# Professional Status Event Contract Analysis

Le catalogue représente exclusivement les deux faits issus des transitions exécutables du workflow 4.5A. L'enregistrement initial du professionnel reste hors workflow et ne produit aucun événement implicite.

Chaque transition produit exactement un type : suspension ou réactivation. Le contrat ne contient aucune publication, infrastructure ou logique de décision.
