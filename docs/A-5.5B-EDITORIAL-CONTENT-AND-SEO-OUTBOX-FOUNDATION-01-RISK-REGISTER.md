# ContentSeo Outbox Risk Register

| Risque | Maîtrise |
|---|---|
| Double écriture | Clé messageId déterministe |
| Divergence sous même identité | Checksum canonique et `DivergentMessage` |
| Concurrence | PK et `ON CONFLICT` déterministes |
| Perte du rollback externe | Savepoint local et transaction propriétaire |
| Retry infini | Borne à dix tentatives |
| Couplage métier | Sources limitées aux deux Delivery V1 |
| Infrastructure diffuse | PostgreSQL limité au Repository dédié |
