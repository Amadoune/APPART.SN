# Anti-abuse Owner-local Runtime Read Foundation

La façade `LeadIngressAntiAbuseRuntimeReadV1` fournit une lecture métier owner-locale à partir de `LeadIngressIntentId` et `LeadIngressAntiAbuseObservedAt`. Elle compose exclusivement `AntiAbuseOwnerSource` et ne dépend d'aucune Infrastructure.

La Persistence sélectionne la révision temporelle ; la politique Runtime Read réduit ce résultat. Aucune règle anti-abus nouvelle n'est créée.
