# Phase 5.3L — Risques et exclusions

## Risques

- historique Git limité à un commit de fondation ;
- baseline applicative accumulée matérialisée en une seule révision ;
- absence de scanner externe spécialisé sur le poste, compensée par un scan
  local multi-signatures documenté ;
- nécessité de ne jamais forcer l'ajout des dépendances, caches ou logs ignorés.

Les campagnes terminales et la matrice de migrations sont vertes. Le risque Git
est levable par le manifeste empreinté, l'indexation contrôlée et un commit
unique de baseline sans modification fonctionnelle.

## Exclusions

5.3L n'autorise aucune fonctionnalité, migration, correction applicative,
modification de test, ouverture Media/Account/Professional, évolution Runtime
Health ou modification d'une frontière certifiée.
