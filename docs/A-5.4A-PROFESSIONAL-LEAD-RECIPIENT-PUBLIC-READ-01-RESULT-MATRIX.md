# A-5.4A — Professional Lead Recipient Public Read — Result Matrix

| Résultat | Autorise la poursuite | Sémantique publique |
|---|---:|---|
| `Eligible` | Oui | le Professional peut recevoir un Lead à l'instant observé |
| `NotEligible` | Non | le Professional ne peut pas recevoir un Lead |
| `Missing` | Non | le Professional canonique est absent |
| `Corrupted` | Non | l'owner ne peut produire une décision cohérente |
| `DependencyUnavailable` | Non | l'owner ne peut répondre |

Le catalogue est fermé. Seul `Eligible` permet à un consumer futur de
poursuivre. Aucun booléen, diagnostic ou exception Infrastructure ne traverse
la frontière.
