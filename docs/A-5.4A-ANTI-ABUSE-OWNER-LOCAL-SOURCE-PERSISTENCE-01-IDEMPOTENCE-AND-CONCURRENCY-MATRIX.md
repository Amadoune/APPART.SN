# Idempotence and Concurrency Matrix

| Cas | Résultat |
|---|---|
| nouvelle révision suivante | `Applied` |
| identité et checksum identiques | `AlreadyApplied` |
| même identité, checksum différent | `DivergentRevision` |
| révision non consécutive | `VersionConflict` |
| deux appends initiaux identiques concurrents | un `Applied`, un `AlreadyApplied` |

La clé primaire PostgreSQL sérialise l'insertion concurrente. Aucun advisory lock n'est nécessaire. L'adapter utilise une transaction owner-locale et un savepoint lorsqu'une transaction englobante existe.
