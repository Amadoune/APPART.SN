# A-5.2C-PROFESSIONAL-STATUS-PUBLIC-READ-01

## Statut d’autorité

**GO CERTIFIÉ — FERMÉ.**

## Objet

L’amendement introduit une frontière Application publique, additive, read-only
et owner F-05. Il ne modifie aucune règle du lifecycle Professional Status.

## Contrat normatif

Le nom versionné retenu est :

```text
ProfessionalPublicStatusReaderV1
```

Signature :

```text
read(ProfessionalId): ProfessionalPublicStatusDecisionV1
```

Catalogue fermé :

| Résultat V1 | Sémantique publique |
|---|---|
| `Available` | F-05 autorise la consommation publique |
| `Unavailable` | F-05 refuse la consommation publique |
| `Missing` | aucune décision F-05 exploitable |
| `Corrupted` | l’état owner ne peut pas être interprété sûrement |
| `DependencyUnavailable` | la source owner ne peut pas produire de décision |

Tous les résultats autres que `Available` sont fail-closed pour le consumer.

## Ownership

| Responsabilité | Owner |
|---|---|
| mapping Active/Suspended vers la décision publique | F-05 |
| implémentation future du reader | F-05 |
| consommation de la décision | Professional Profile 5.2C |
| visibilité volontaire du profil | ProfessionalPublicProfile 5.2C |
| composition finale de publication | Professional Profile 5.2C |

Le consumer ne reçoit jamais l’état `Active/Suspended` et ne peut donc pas
reconstruire ou réinterpréter le lifecycle.

## Confidentialité et stabilité

La frontière n’expose pas :

- `ProfessionalStatusStoredState` ;
- version, expected version ou historique ;
- action, transition, actor ou contexte ;
- diagnostic interne ;
- exception, SQL, table, repository ou transaction ;
- Runtime, provider ou transport owner.

La version `V1` appartient au nom du contrat et au résultat. Toute extension du
catalogue exige une nouvelle version ou un amendement compatible explicite.

## Compatibilité

| Surface gelée | Impact |
|---|---|
| Aggregate F-05 | aucun |
| Workflow Active/Suspended | aucun |
| Orchestrator | aucun |
| Runtime F-05 certifié | aucun |
| HTTP F-05 | aucun |
| Event Catalog / Delivery / Outbox | aucun |
| persistence / migrations | aucun |
| Runtime Health | aucun, 58 capacités conservées |

## Portée technique

L’amendement crée uniquement :

- l’interface Application `ProfessionalPublicStatusReaderV1` ;
- l’enum fermé `ProfessionalPublicStatusDecisionV1` ;
- leurs preuves Unit et Architecture.

Il ne crée aucune implémentation, lecture SQL, projection, cache, composition
Runtime, route ou binding. La future implémentation owner F-05 devra faire
l’objet du jalon explicitement autorisé par l’autorité.

## Décision proposée

**GO.**

La frontière normative est minimale, additive, owner-scoped, versionnée et
fail-closed. Elle préserve intégralement F-05.
