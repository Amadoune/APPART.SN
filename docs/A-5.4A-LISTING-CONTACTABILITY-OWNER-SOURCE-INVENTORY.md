# 5.4A — Listing Contactability Owner Source Inventory

## Source retenue

`ListingPublicationWorkflowStore::read(ListingId)` est la source owner retenue.

| Propriété | Qualification |
|---|---|
| Owner | ListingLifecycle |
| Couche | port Application owner, implémentation Infrastructure existante |
| Certification | F-01 et persistence Listing existantes |
| Accès | lecture exacte par `ListingId` |
| Données utiles | existence qualifiée, état owner courant, cohérence, version interne non exposée |
| Caractère borné | clé Listing, dernier état uniquement |
| Stabilité | contrat déjà consommé par les frontières owner Listing |
| Migration requise | aucune |

Le repository PostgreSQL existant applique une requête bornée par
`listing_id`, ordonnée par version décroissante avec `LIMIT 1`. Le reader
public ne reçoit ni PDO ni SQL et n'expose jamais le snapshot.

## Conclusion

La source existante satisfait la Foundation sans scan, nouvelle persistence,
projection ou migration.
