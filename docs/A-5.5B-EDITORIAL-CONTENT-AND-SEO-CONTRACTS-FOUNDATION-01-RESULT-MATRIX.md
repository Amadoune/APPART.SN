# Editorial Content & Operational SEO — Result Matrix V1

## Editorial Content

| Statut | Sens public |
|---|---|
| `Published` | Contenu éditorial publiable selon `ContentSeo` |
| `Unpublished` | Contenu connu mais non publiable |
| `Missing` | Aucune décision éditoriale publique |
| `Corrupted` | Décision owner-locale inexploitable |
| `DependencyUnavailable` | Lecture publique indisponible |

## Operational SEO

| Statut | Sens public |
|---|---|
| `Indexable` | Traitement SEO autorise l'indexation |
| `NoIndex` | Traitement SEO interdit l'indexation |
| `Missing` | Aucune décision SEO publique |
| `Corrupted` | Décision owner-locale inexploitable |
| `DependencyUnavailable` | Lecture publique indisponible |

Aucun fallback et aucun autre statut ne sont admis.
