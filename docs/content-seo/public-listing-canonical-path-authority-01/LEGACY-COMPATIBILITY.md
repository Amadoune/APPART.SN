# Legacy Compatibility

Les Listings déjà dotés d’une canonical descriptive conservent cette canonical. Ils ne sont pas renommés vers le modèle UUID.

La règle UUID s’applique aux Listings sans canonical autoritative, notamment RC2. Aucun redirect n’est créé entre une URL qui n’a jamais existé et la nouvelle canonical.

Si une future migration change une canonical existante, elle devra utiliser les autorités Historical Canonical/Redirect déjà certifiées dans un chantier distinct.
