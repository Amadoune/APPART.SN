# Public Listing Canonical Path Authority 01

## Décision

Pour tout nouveau Listing public, ContentSeo décide :

`canonicalPath = annonces/{listingId}`

où `listingId` est l’UUID canonique minuscule du Listing.

Le chemin est immuable, globalement unique, déterministe et indépendant du contenu. Il ne contient ni hostname ni slash initial/final. Les canonicales historiques déjà publiées sont préservées.
