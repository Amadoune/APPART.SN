# Published Handoff Evidence

Après routage certifié de `ListingPublished` et matérialisation Search réussie, le consumer appelle ContentSeo avec le seul `ListingId`. Les réductions sont explicites: succès/obsolète consommé, source non prête bloquée, dépendance retryable, corruption/divergence permanente. Search et ContentSeo conservent leurs transactions distinctes.
