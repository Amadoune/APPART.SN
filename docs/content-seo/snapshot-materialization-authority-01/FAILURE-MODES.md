# Failure Modes

Catalogue fail-closed proposé pour l’implémentation : `ListingMissing`, `ListingNotPublished`, `TitleMissing`, `DescriptionMissing`, `CanonicalUnresolved`, `IndexabilityUnresolved`, `DecisionTimeUnresolved`, `SourceMissing`, `SourceRevisionInvalid`, `SourceCorrupted`, `DependencyUnavailable`, `RejectedObsolete`, `Divergent`, `Applied`, `AlreadyApplied`.

Aucun fallback vers UI, Projection, horloge courante ou contenu inventé n’est permis.
