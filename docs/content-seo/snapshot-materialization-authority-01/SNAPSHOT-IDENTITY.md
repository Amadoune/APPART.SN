# Snapshot Identity

Identité retenue par cette Authority : UUIDv5 déterministe, namespace URL RFC 4122.

Policy identity : `content-seo-snapshot-materialization-policy-v1`.

Nom canonique :

`https://appart.sn/content-seo/public-source-snapshots/content-seo-snapshot-materialization-policy-v1/{listingId}`

Le même Listing sous la même policy conserve donc le même `snapshotId`. Aucun UUID aléatoire n’est autorisé.
