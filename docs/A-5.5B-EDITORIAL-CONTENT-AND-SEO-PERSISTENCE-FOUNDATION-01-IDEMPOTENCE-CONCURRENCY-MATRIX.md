# Editorial Content & Operational SEO — Idempotence & Concurrency Matrix

| Situation | Résultat |
|---|---|
| Même révision, même checksum | AlreadyApplied |
| Même révision, checksum différent | DivergentRevision |
| Première révision différente de 1 | VersionConflict |
| Saut ou régression de révision | VersionConflict |
| Révision suivante valide | Applied |
| Concurrence sur un même stream | Verrou advisory transactionnel, un gagnant |
| Transaction appelante existante | Savepoint local, rollback externe conservé |

Le journal et l'index convergent atomiquement dans une transaction owner-locale.
