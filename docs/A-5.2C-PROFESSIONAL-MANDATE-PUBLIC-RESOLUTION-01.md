# A-5.2C-PROFESSIONAL-MANDATE-PUBLIC-RESOLUTION-01

## Statut d’autorité

**GO CERTIFIÉ — FERMÉ.**

## Contrat normatif

Le nom retenu est :

```text
ProfessionalMandateResolverV1
```

Signature :

```text
resolve(accountId opaque): ProfessionalMandateResolutionV1
```

L’`accountId` est une référence UUID canonique reçue d’IAM et transportée comme
scalaire opaque. Professional Core ne dépend ainsi ni du modèle IAM, ni de ses
stores, ni de son Runtime.

## Résultat fermé

| Statut V1 | Donnée exposée | Décision du consumer |
|---|---|---|
| `Resolved` | `ProfessionalId` uniquement | autorisation poursuivie |
| `NotMandated` | aucune | fail-closed |
| `Ambiguous` | aucune | fail-closed |
| `Corrupted` | aucune | fail-closed |
| `DependencyUnavailable` | aucune | fail-closed |

`ProfessionalMandateResolutionV1` interdit structurellement qu’un résultat
autre que `Resolved` porte un `ProfessionalId`.

## Ownership

| Responsabilité | Owner |
|---|---|
| interprétation de la référence Account | Professional Core à sa frontière |
| sélection des mandats actifs | Professional Core |
| résolution unique vers ProfessionalId | Professional Core |
| authentification et émission de l’AccountId | IAM F-17 |
| consommation pour l’auto-scope HTTP | Professional Profile 5.2C |

IAM ne connaît ni mandat, ni établissement, ni Professional. Professional
Profile ne voit jamais `RepresentativeId` et ne peut pas recalculer la
résolution.

## Confidentialité

La frontière n’expose pas :

- Aggregate `Professional` ;
- `RepresentativeId` ou `RepresentativeMandate` ;
- `MandateId`, rôle, dates ou historique ;
- établissement ;
- registration number ;
- SQL, table, repository, version ou transaction ;
- diagnostic Runtime ou IAM.

## Déterminisme

Une future implémentation doit retourner :

- `Resolved` seulement lorsqu’un unique Professional est autorisé par les
  mandats actifs ;
- `NotMandated` lorsqu’aucun mandat actif ne correspond ;
- `Ambiguous` lorsque plusieurs Professionals restent possibles ;
- `Corrupted` lorsque les données owner sont incohérentes ;
- `DependencyUnavailable` lorsque la source owner ne peut être lue.

Elle ne doit effectuer aucun choix arbitraire en cas de pluralité.

## Compatibilité

| Surface | Impact de l’amendement |
|---|---|
| Aggregate Professional | aucun |
| RepresentativeMandate | aucun |
| IAM F-17/F-18 | aucun |
| persistence / migrations | aucun |
| Runtime / HTTP | aucun |
| Event Catalog / Delivery / Outbox | aucun |

## Portée technique

L’amendement crée uniquement :

- `ProfessionalMandateResolverV1` ;
- `ProfessionalMandateResolutionV1` ;
- `ProfessionalMandateResolutionStatusV1` ;
- leurs preuves Unit et Architecture.

Aucun adapter, binding, SQL, projection, cache ou Runtime n’est créé.

## Décision proposée

**GO.**

La frontière est minimale, versionnée, owner Professional Core, déterministe et
fail-closed sans modifier les capacités existantes.
