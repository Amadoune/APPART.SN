# Temporal Read Matrix

| Situation | Résultat |
|---|---|
| aucune révision effective à `observedAt` | `Missing` |
| une ou plusieurs révisions | dernière par `effective_at DESC, revision DESC` |
| checksum invalide ou ligne incohérente | `Corrupted` |
| dépendance indisponible | `DependencyUnavailable` |

La lecture est owner-locale, déterministe et read-only.
