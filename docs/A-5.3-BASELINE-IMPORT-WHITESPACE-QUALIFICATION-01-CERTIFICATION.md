# A-5.3-BASELINE-IMPORT-WHITESPACE-QUALIFICATION-01 — Certification

## Représentation

L'audit couvre exclusivement les 239 fichiers signalés par
`git diff --cached --check` :

- 220 Markdown ;
- 19 SQL ;
- aucun autre fichier.

Chaque fichier possède exactement deux LF terminaux. La normalisation proposée
retirerait exclusivement le second LF, soit un octet `0A`.

## Garanties démontrées

- aucun caractère utile ne serait modifié ;
- aucun token, littéral, commentaire ou ordre SQL ne serait modifié ;
- les 19 SQL finissent par un point-virgule avant les deux LF ;
- tous les rollbacks associés existent ;
- le rendu et la structure Markdown resteraient identiques ;
- seuls les hashes binaires et Git changeraient ;
- aucun checksum métier ne dépend des octets concernés ;
- aucune exception Git n'est recommandée.

Les 19 fichiers SQL relèvent tous de capacités gelées :

- migration 043 : F-09/F-16 ;
- migrations 044 à 053 : F-18.

## Recommandation de preuve

Après autorisation de la normalisation :

1. vérifier la liste exacte des 239 chemins ;
2. retirer exactement un LF terminal par fichier ;
3. démontrer une différence d'un octet par fichier ;
4. exécuter Architecture complète ;
5. exécuter PostgreSQL complet ;
6. régénérer le manifeste SHA-256 ;
7. obtenir `git diff --cached --check` et `git diff --check` PASS.
