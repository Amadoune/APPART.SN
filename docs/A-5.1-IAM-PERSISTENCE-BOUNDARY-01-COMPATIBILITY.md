## Compatibilité comportementale

Les tests PostgreSQL relancent les neuf scénarios 5.1C/5.1D sans adaptation
fonctionnelle : round-trips des huit owners, idempotence, version conflict,
rollback, concurrence deux processus, seed, quarantaine, cutover et rollback.

Le remplacement est un déplacement de responsabilité de type, pas une
nouvelle capacité.

Le mapper de Seed ne révèle que les cinq faits déjà consommés avant
l'amendement. Aucun secret ou sous-graphe Historical Account supplémentaire
n'est rendu accessible.
