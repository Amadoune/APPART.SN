# A-5.4B Reservation Availability Public Read — Compatibility Matrix

| Capacité | Impact | Garantie |
|---|---|---|
| ListingLifecycle | contrat Application additif uniquement | Aggregate, transitions et Readers certifiés inchangés |
| RealEstateCatalog | contrat Application additif uniquement | Property, Registry, authoring et persistence inchangés |
| ReservationLifecycle | contrat Application pré-intake avec identités owner-locales | workflow, orchestrateur, `ReservationId`, migration 019 et Events inchangés |
| IdentityAccess | aucun changement | décision Account demeure indépendante |
| Reservation Intake Handoff | aucune consommation encore | future composition derrière décisions certifiées |
| 5.4A | aucun changement | Consent et Anti-abuse restent gelés |
| Phase 5.3 | aucun changement | périmètre gelé préservé |

Aucune interface n'importe un type d'un autre module. Chaque frontière réutilise
exclusivement l'identité de son owner.

`ReservationAvailabilityIntentId` et `ReservationAvailabilitySubjectId` sont
de nouvelles identités de contrat pré-intake ; elles ne remplacent pas
`ReservationId` et n'importent aucune identité Listing ou Property.
