# Anti-abuse Owner-local Source Runtime Foundation

`AntiAbuseOwnerSourceRuntimeV1` expose exclusivement la disponibilité technique de la source owner `ContactsLeads`. La composition certifiée est : Runtime V1 → politique de disponibilité → `AntiAbuseOwnerSource` → adapter PostgreSQL.

La façade ne fournit aucune lecture métier et ne constitue pas une implémentation de `LeadIngressAntiAbuseReaderV1`.

## Surface

- `availability()` retourne un catalogue fermé ;
- `diagnostics()` retourne uniquement l'identifiant Runtime, sa version et l'état fermé ;
- aucun identifiant d'intention, état persistant, révision, checksum ou diagnostic Infrastructure n'est exposé.
