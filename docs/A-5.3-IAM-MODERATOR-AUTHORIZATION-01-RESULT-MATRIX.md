# A-5.3-IAM-MODERATOR-AUTHORIZATION-01 — Result Matrix

| Résultat | Sens public | Autorise l'action |
|---|---|---|
| `Allowed` | le compte est autorisé pour la capacité observée | oui |
| `Denied` | le compte n'est pas autorisé | non |
| `Corrupted` | l'autorité IAM ne peut produire une décision fiable | non |
| `DependencyUnavailable` | une dépendance nécessaire est indisponible | non |

Tous les résultats autres que `Allowed` sont fail-closed.

Le catalogue ne contient aucun résultat ouvert, booléen ou exception technique.
