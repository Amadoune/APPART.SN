# Official Remote and External CI Authority Resolution 01 — Resolution Matrix

| Exigence d'autorité | Preuve observée | Statut | Résolution requise |
|---|---|---|---|
| Repository officiel | Aucun remote et aucune désignation | MISSING | Décision explicite de l'autorité projet |
| Owner officiel | Aucun compte ou organisation désigné | MISSING | Nommer l'owner externe |
| URL Git officielle | Absente | MISSING | Fournir l'URL exacte |
| Principal de publication/vérification R5 | Non désigné | MISSING | Nommer le principal et ses droits |
| Tag R5 distant exact | Non observable | BLOCKED | Vérifier après désignation du remote |
| GitHub Actions activé | Non attesté | MISSING | Attestation de l'owner officiel |
| Permissions Actions | Déclaration locale seulement | PARTIAL | Vérifier la politique effective distante |
| Opérateur de déclenchement | Non désigné | MISSING | Nommer opérateur ou principal automatisé |
| Run permanent R5 | Aucun | BLOCKED | Exécuter après résolution d'autorité |
| Conservation des preuves | Rétention workflow de 30 jours seulement | PARTIAL | Désigner stockage durable et owner |
| Reproduction indépendante | Aucun second environnement/opérateur | MISSING | Désignation explicite |

Une seule absence suffit au NO GO. Plusieurs dépendances d'autorité restent simultanément manquantes.
