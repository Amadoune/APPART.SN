# Query Resolution Owner Source Implementation Foundation

Owner unique : `SearchDiscovery`. La frontière Application reçoit une
`SearchQuery` réelle et un `SearchQueryResolutionObservedAt`, puis consulte
exclusivement `SearchQueryResolutionOwnerSource`. Aucun Runtime, Provider ou
composant Infrastructure ne participe à la composition.

Signature : `read(SearchQuery, SearchQueryResolutionObservedAt): SearchQueryResolutionOwnerResult`.
