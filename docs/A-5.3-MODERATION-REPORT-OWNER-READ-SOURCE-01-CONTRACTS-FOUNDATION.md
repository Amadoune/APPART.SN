# A-5.3-MODERATION-REPORT-OWNER-READ-SOURCE-01 — Contracts Foundation

## Port

`ModerationReportOwnerReadSourceV1::resolve(reportId)`

Le port appartient à Application, est read-only et ne dépend ni de Laravel, ni
de PDO, ni de PostgreSQL.

## Catalogue fermé

| Résultat | État |
|---|---|
| `Found` | état minimal présent |
| `Missing` | dossier canonique absent |
| `Corrupted` | identité invalide ou incohérence dossier/report |
| `DependencyUnavailable` | source technique indisponible |

`ModerationReportOwnerReadState` expose exclusivement :

- `caseId` ;
- `reportId` ;
- `reporterAccountId`.

Aucun snapshot, payload, finding, décision, preuve, intent ou checksum n'est
exposé.

## Identité canonique

Le port interne `ModerationReportCaseIdentityV1` évite toute duplication de
l'algorithme. Son implémentation délègue à l'autorité existante
`CanonicalModerationCommand::deterministicUuid`.
