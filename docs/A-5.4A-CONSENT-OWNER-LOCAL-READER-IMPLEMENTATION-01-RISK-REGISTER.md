# Owner Reader Risk Register

| Risque | Niveau | Mitigation |
|---|---|---|
| logique métier ajoutée au Reader | élevé | mapping exhaustif un-à-un |
| fuite Runtime ou Persistence | élevé | résultat public limité au statut |
| accès direct à Infrastructure | élevé | dépendance unique à Runtime Read |
| horloge ou calcul temporel implicite | élevé | instant transmis sans transformation |
| binding multiple | moyen | Provider dédié, alias singleton et test container |
| gate historique interdisant le binding désormais requis | élevé | amendement d'alignement Architecture requis avant certification |
