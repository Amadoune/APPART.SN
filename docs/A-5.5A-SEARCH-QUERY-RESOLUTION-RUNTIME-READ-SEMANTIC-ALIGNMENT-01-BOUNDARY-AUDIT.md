La Runtime Read candidate expose `read()` sans `SearchQuery` ni instant
d'observation. Son mapping `Available -> Found` transforme donc une preuve de
disponibilité technique en résultat fonctionnel sans exécution de requête.
`Empty` est structurellement inatteignable.

distincte de la Runtime Health, recevant `SearchQuery` et
`SearchQueryResolutionObservedAt`. Elle consulte exclusivement le port
owner-local `SearchQueryResolutionOwnerSource` et produit mécaniquement
`Found`, `Empty`, `Corrupted` ou `DependencyUnavailable`.

La Runtime Read candidate est NO GO TECHNIQUE CERTIFIÉ — FERMÉ. Elle ne doit
entrer dans aucune composition future. Son retrait physique éventuel exigera un
jalon correctif technique distinct ; aucun fichier n'est supprimé par l'audit.
