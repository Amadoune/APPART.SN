# HTTP Matrix

| Statut public | HTTP |
|---|---:|
| Available | 200 |
| Missing | 404 |
| Corrupted | 503 |
| DependencyUnavailable | 503 |

Cette matrice s'applique sans fallback aux sept familles : ResponsiveCompliance, AccessibilityCompliance, UserExperience, EndToEndReadiness, PerformanceReadiness, UserAcceptance et ReleaseCandidate.
