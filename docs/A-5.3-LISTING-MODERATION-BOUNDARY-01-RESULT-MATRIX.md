# A-5.3-LISTING-MODERATION-BOUNDARY-01 — Result Matrix

## Reader

| Résultat | Signification | Éligible |
|---|---|---|
| `Eligible` | la cible peut être modérée à l'instant observé | oui |
| `Ineligible` | la cible existe mais ne peut être modérée | non |
| `Missing` | aucune cible canonique correspondante | non |
| `Corrupted` | l'autorité ne peut produire une lecture fiable | non |
| `DependencyUnavailable` | une dépendance owner Listing est indisponible | non |

## Gateway

| Résultat | Signification |
|---|---|
| `Applied` | la demande a été appliquée par Listing |
| `AlreadyApplied` | le même commandId et checksum est terminal |
| `Rejected` | l'action est refusée par le workflow existant |
| `DivergentIntent` | même commandId, checksum différent |
| `VersionConflict` | une évolution concurrente empêche l'application |
| `DependencyUnavailable` | Listing ne peut rendre une décision fiable |

Aucun booléen, exception technique ou résultat ouvert n'est exposé.
