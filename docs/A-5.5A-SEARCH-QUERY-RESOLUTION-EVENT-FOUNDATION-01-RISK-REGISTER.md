# Risk Register

| Risque | Maîtrise |
|---|---|
| décision Event autonome | source unique : Reader public |
| événement multiple | un appel produit exactement un événement |
| fuite de requête ou PII | payload limité au statut et à l'instant |
| dépendance Runtime/Persistence | gate Architecture négative |
| ouverture implicite du transport | aucun Provider, Routing, Delivery ou Outbox |
