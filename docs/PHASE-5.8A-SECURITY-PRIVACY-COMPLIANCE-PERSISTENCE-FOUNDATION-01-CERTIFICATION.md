# Certification

Le périmètre certifiable comprend uniquement la source owner-scoped, les quinze types Application, le mapper, le repository PostgreSQL, la migration 086 et son rollback.

Les preuves autorisées sont les campagnes Unit, Architecture, PostgreSQL ciblé, PHPStan, Pint et `git diff --check`. Aucun test Feature, HTTP, Event, Delivery ou Outbox n'appartient à cette campagne.

Sous réserve du succès des validations, le statut proposé est `GO PROPOSÉ — PHASE-5.8A-SECURITY-PRIVACY-COMPLIANCE-PERSISTENCE-FOUNDATION-01`.
