# A-5.5A Search Experience Boundary — Risk Register

| Risque | Niveau | Mitigation documentaire |
|---|---|---|
| Search duplique le lifecycle Listing | élevé | frontière publique minimale owner Listing |
| Public Projection devient autorité | élevé | projection limitée au rendu |
| ranking possédé par Listing ou SEO | élevé | ownership exclusif SearchDiscovery |
| reconstruction ad hoc depuis Events | élevé | index Search owner-local versionné |
| données privées indexées | élevé | liste blanche publique et minimisation |
| Runtime Health décide la visibilité | élevé | séparation technique/métier |
| source obsolète ou incohérente | élevé | revisions, fraîcheur et fail-closed futurs |
| cycle Search ↔ SEO | élevé | flux Search vers SEO unidirectionnel |
| cache utilisé comme vérité | moyen | cache sous index owner-local, reconstructible |
| baseline gelée modifiée | élevé | amendements versionnés obligatoires |
