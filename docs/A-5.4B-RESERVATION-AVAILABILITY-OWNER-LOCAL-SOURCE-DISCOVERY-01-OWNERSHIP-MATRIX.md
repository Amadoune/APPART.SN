# A-5.4B Reservation Availability Source — Ownership Matrix

| Élément | Owner | Autorité | Exclusion |
|---|---|---|---|
| intent Availability | `ReservationLifecycle` | identité, révisions et idempotence | Listing, Property, IAM |
| sujet réservable opaque | `ReservationLifecycle` | partition locale des conflits | aucune identité externe exposée |
| fenêtre demandée | `ReservationLifecycle` | intervalle de la tentative | aucun calendrier Property |
| conflit temporel | `ReservationLifecycle` | chevauchement des occupations locales | aucune reconstruction Event |
| réservabilité Listing | `ListingLifecycle` | décision publique indépendante | non persistée par cette source |
| éligibilité Property | `RealEstateCatalog` | décision publique indépendante | non persistée par cette source |
| autorisation Account | `IdentityAccess` | décision publique indépendante | aucune PII dans la source |

La source ne devient pas owner des décisions externes. Leur future corrélation
avec l'intent doit rester une composition de résultats fermés, hors du journal
de disponibilité.
