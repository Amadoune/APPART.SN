# A-5.4C Account Closure Data Lifecycle — Risk Register

| Risque | Niveau | Mitigation documentaire |
|---|---|---|
| collection lisible après `Closed` | élevé | blocage immédiat de toute vue et commande |
| IAM supprime chez Favorites | élevé | aucune écriture cross-domain |
| rétention indéfinie | élevé | politique Favorites/Privacy versionnée obligatoire |
| suppression prématurée | élevé | aucune purge sur le seul fait `Closed` |
| legal hold ignoré | élevé | purge interdite sous hold |
| réouverture après erasure | élevé | erasure irréversible, réouverture impossible |
| état Archive inventé | moyen | aucun état supplémentaire dans cet audit |
| événement interne exposant la collection | élevé | faits minimaux, aucune entrée ni ListingId |
| transaction distribuée | élevé | traitement owner-local et idempotent futur |
| baseline gelée modifiée | élevé | futurs jalons versionnés obligatoires |
