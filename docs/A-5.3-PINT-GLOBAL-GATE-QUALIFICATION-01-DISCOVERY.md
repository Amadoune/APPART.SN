# A-5.3-PINT-GLOBAL-GATE-QUALIFICATION-01 — Discovery

## Statut

QUALIFICATION DOCUMENTAIRE — AMENDEMENT 5.3G REQUIS

## Objet

Qualifier la dernière gate empêchant la certification de
`A-5.3-MODERATION-REPORT-OWNER-READ-SOURCE-01`, sans modifier le code.

## Preuve actuelle

La commande globale non modifiante :

```text
vendor/bin/pint --test
```

produit un exit code 1 sur un seul fichier :

```text
app/Application/ModerationEventTransport/ModerationEventTransportSerializer.php
```

Fixers signalés :

- `class_attributes_separation` ;
- `unary_operator_spaces` ;
- `not_operator_with_successor_space`.

Le fichier appartient à 5.3G, capacité certifiée et gelée. Aucun fichier de la
fondation Report n'est signalé et Pint ciblé Report est PASS.

## Règles applicables

- `PHASE-5.0B-QUALITY-BASELINE.md` impose Pint et `git diff --check`
  obligatoirement verts.
- `PHASE-5.0B-CERTIFICATION-RULES.md` autorise un GO uniquement lorsque toutes
  les gates applicables sont PASS.
- `PHASE-5.0B-GOVERNANCE.md` interdit la modification d'une capacité gelée sans
  amendement versionné.
- Le Blueprint 5.3 exige explicitement Pint PASS.

## Qualification

L'écart n'est pas un défaut fonctionnel Report. Il bloque néanmoins sa
certification globale. Les règles ne définissent aucune procédure de waiver
permettant de transformer une gate rouge en PASS.

Une dérogation créée pour ce cas modifierait l'interprétation normative de la
gate et certifierait avec une commande obligatoire en échec. Elle n'est donc pas
recevable sous les règles en vigueur.

## Décision recommandée

Ouvrir un amendement versionné 5.3G strictement limité à la restauration de Pint
global PASS. Cet audit ne l'ouvre pas et ne corrige aucun fichier.

## Verdict proposé

**GATE PINT BLOQUANTE — AMENDEMENT VERSIONNÉ 5.3G REQUIS.**
