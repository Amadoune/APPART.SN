# Certification

Le périmètre contient uniquement le port Application, ses états et résultats, le mapper, l'adapter PostgreSQL, la migration additive 082 et son rollback. Le journal est append-only, l'index est dérivé et les transactions sont owner-locales.

La certification est proposée après PASS des campagnes Unit, Architecture, PostgreSQL, PHPStan, Pint et `git diff --check`.
