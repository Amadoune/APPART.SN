# A-5.4B Reservation Availability Persistence — Application Contracts

```text
append(ReservationAvailabilityRevisionState)
    -> ReservationAvailabilityWriteResult

read(IntentId, SubjectId, Window, ObservedAt)
    -> ReservationAvailabilityReadResult

history(IntentId)
    -> list<ReservationAvailabilityRevisionState>
```

Résultats d'écriture fermés : `Applied`, `AlreadyApplied`,
`DivergentRevision`, `VersionConflict`, `AvailabilityConflict`, `Corrupted`,
`DependencyUnavailable`.

Résultats de lecture fermés : `Available`, `Conflicting`, `Missing`,
`Corrupted`, `DependencyUnavailable`.

L'Application ne dépend ni de PDO, ni de PostgreSQL, ni de Laravel.
