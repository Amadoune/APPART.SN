# A-5.4A — Listing Contactability — Result Matrix

| Résultat V1 | Autorise la poursuite | Divulgue une cause | Comportement |
|---|---:|---:|---|
| `Contactable` | oui | non | le consumer peut poursuivre ses propres contrôles |
| `NotContactable` | non | non | refus fermé sans état lifecycle |
| `Missing` | non | non | absence traitée selon l'anti-énumération du consumer |
| `Corrupted` | non | non | refus fermé, aucun diagnostic public |
| `DependencyUnavailable` | non | non | refus fermé distinct d'une décision négative |

## Exhaustivité

Le catalogue contient exactement cinq résultats. Aucun booléen, résultat
nullable, exception métier ou extension implicite n'est autorisé.

## Séparation normative

- `NotContactable` est une décision owner Listing ;
- `Missing` est une absence qualifiée, jamais une preuve de suppression ;
- `Corrupted` représente l'impossibilité de faire confiance à l'état owner ;
- `DependencyUnavailable` représente une indisponibilité et ne doit jamais
  être converti en `NotContactable` ;
- seul `Contactable` est positif.

Le contrat ne transporte ni motif, statut interne, identifiant professionnel,
coordonnée, PII, Snapshot ou version brute.
