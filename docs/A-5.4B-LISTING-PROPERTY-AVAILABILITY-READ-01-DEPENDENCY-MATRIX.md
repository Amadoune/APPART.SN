# A-5.4B Listing/Property Availability — Dependency Matrix

| Producteur | Consumer | Décision minimale | Nécessité | Interdit |
|---|---|---|---|---|
| ListingLifecycle | ReservationLifecycle | réservable / non réservable / indisponible | obligatoire | Aggregate, Repository, Snapshot, SQL Listing |
| RealEstateCatalog | ReservationLifecycle | Property éligible / non éligible / absent | obligatoire | Aggregate, Registry, Store, SQL Property |
| ReservationLifecycle | Reservation intake | fenêtre disponible / conflictuelle / inconnue | obligatoire | Event, projection, cache |
| IdentityAccess | Reservation intake | Account autorisé et auto-scopé | obligatoire mais distinct | AccountId fourni librement, Aggregate IAM |
| ContactsLeads | Reservation | aucun flux | interdit | consentement et anti-abus Lead |

## Ordre conceptuel

Les décisions Listing et Property sont des lectures owner indépendantes. La
décision temporelle est calculée dans Reservation sur son propre état. Leur
composition future doit être fail-closed, sans transaction distribuée et sans
faire d'un consumer l'autorité d'une décision externe.
