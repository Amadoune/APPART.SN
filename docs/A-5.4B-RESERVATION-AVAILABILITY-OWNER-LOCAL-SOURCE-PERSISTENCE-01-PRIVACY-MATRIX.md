# A-5.4B Reservation Availability Persistence — Privacy Matrix

Persistés exclusivement : intent UUID, sujet UUID opaque, fenêtre UTC, état,
révision, instants d'effet/enregistrement et checksum.

Interdits et absents : ListingId, PropertyId, AccountId, FK cross-domain, PII,
adresse, email, téléphone, texte libre, diagnostic PostgreSQL, secret ou token.

Le modèle ne contient aucune cascade ni trigger. La politique de rétention
reste une décision ultérieure ; aucune donnée externe n'est requise pour
préserver l'intégrité du journal.
