# Notifications Delivery Matrix

| Event | Statuts propagés |
|---|---|
| PreferenceObserved | Enabled, Disabled, Missing, Corrupted, DependencyUnavailable |
| TemplateObserved | Available, Missing, Corrupted, DependencyUnavailable |
| ChannelObserved | Allowed, Blocked, Missing, Corrupted, DependencyUnavailable |

La propagation type/statut/observedAt est bijective et sans fallback.
