# A-5.4A Consent Owner-local Source — Runtime Foundation

## Architecture

Le Runtime appartient exclusivement à `ContactsLeads` et compose la baseline
certifiée dans un seul sens :

`ConsentOwnerSource` → `PostgreSqlConsentOwnerSource` → politique de
disponibilité → façade Runtime V1.

La façade Application est framework-agnostic. Elle n'expose aucun état métier,
aucune donnée utilisateur et aucun diagnostic Infrastructure.

## Composition

Le Provider Runtime enregistre des singletons lazy et uniques pour le mapper,
le Store, le port, la politique de disponibilité et la façade. Il n'étend pas
le Runtime Health historique et ne dépend d'aucun autre owner.

## Frontières préservées

Aucun Reader concret, HTTP, Controller, Route, Event, Delivery, Outbox,
orchestration, anti-abus, Privacy ou Erasure n'est créé. Le Store, le Mapper,
le port, le State et la migration 072 restent inchangés.
