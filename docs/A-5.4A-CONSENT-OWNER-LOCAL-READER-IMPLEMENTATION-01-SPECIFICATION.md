# Owner Reader Implementation Foundation Specification

`OwnerLeadContactConsentReaderV1`, owner `ContactsLeads`, implémente le contrat
public `LeadContactConsentReaderV1`. Sa dépendance unique est
`ConsentOwnerSourceRuntimeReadV1`.

Le Reader transmet sans transformation `LeadIngressIntentId` et
`LeadConsentObservedAt`, puis adapte mécaniquement le statut Runtime vers le
statut public homonyme. Il ne contient aucune sélection temporelle, décision
métier, logique Persistence ou consultation Runtime Health.
