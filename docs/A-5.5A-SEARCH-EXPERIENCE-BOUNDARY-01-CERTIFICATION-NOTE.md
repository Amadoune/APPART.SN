# A-5.5A Search Experience Boundary — Certification Note

Recommandation : retenir `SearchDiscovery` comme owner unique d'une Search
Experience autonome.

- ListingLifecycle produit uniquement une future décision publique minimale
  d'indexabilité ;
- Search compose les sources publiques, possède son index, sa visibilité, son
  ranking, ses facettes, sa pagination et sa future API ;
- Public Projection assure le rendu sans devenir autorité ;
- ContentSeo reste owner des décisions SEO et ne pilote pas Search ;
- tout résultat non explicitement admissible est exclu en fail-closed.

Aucun contrat PHP, Runtime, Reader, Provider, Persistence, migration, SQL, HTTP,
Event, Delivery, Outbox, test ou composant exécutable n'est créé.
