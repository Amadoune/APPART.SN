# Availability Policy

| Résultat source | Disponibilité Runtime |
|---|---|
| `Available` | `Available` |
| `Conflicting` | `Available` |
| `Missing` | `Available` |
| `Corrupted` | `Corrupted` |
| `DependencyUnavailable` | `DependencyUnavailable` |
| exception technique | `DependencyUnavailable` |

`Available` signifie uniquement que la source répond de manière exploitable.
La politique ne transporte ni état, ni fenêtre, ni révision, ni décision métier.
