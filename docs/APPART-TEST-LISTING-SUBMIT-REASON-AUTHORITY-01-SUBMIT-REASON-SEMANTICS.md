# Listing Submit Reason Authority 01 — Semantics

Un reason Submit devrait exprimer une motivation métier distincte de l'action et être disponible avant mutation. Aucun besoin produit, choix fermé ou texte contraint n'est actuellement qualifié.

Les valeurs « submit », « submitted », « publication » ou « user action » ne répondent pas à cette sémantique et sont rejetées.
