# A-5.4C Public Listing Eligibility — Result Matrix

| Statut | Favorites peut poursuivre | Sens public |
|---|---|---|
| `Eligible` | oui | Listing éligible à l'instant observé |
| `NotEligible` | non | Listing existant mais non éligible |
| `Missing` | non | Listing absent |
| `Corrupted` | non | décision non fiable |
| `DependencyUnavailable` | non | décision indisponible |

Le catalogue est fermé. Seul `Eligible` autorise la poursuite. Le résultat ne
contient que le statut.
