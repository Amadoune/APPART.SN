# A-5.5A Search Experience Boundary — Boundary Audit

## Autorités

`SearchDiscovery` est l'owner unique de l'expérience de recherche publique :
index de recherche, composition des sources publiques, visibilité dans les
résultats, facettes, classement, pagination et API Search future.

`ListingLifecycle` reste l'autorité d'une décision publique minimale indiquant
si un Listing est indexable. Il ne possède ni l'index, ni le classement, ni les
résultats. Public Projection sert le rendu public et ne devient pas source de
vérité. `ContentSeo` possède exclusivement les décisions SEO.

## Source de vérité

La source de vérité servie par Search est une projection/index owner-local
`SearchDiscovery`, produite à partir de faits ou frontières publiques versionnés
des owners. Elle est autoritative pour les résultats de recherche, mais jamais
pour le lifecycle Listing, Property ou Media.

## Frontières minimales

- décision publique d'indexabilité Listing, owner `ListingLifecycle` ;
- décisions publiques Property et Media nécessaires à la composition, sous
  leurs owners respectifs ;
- surface de query Search owner-scoped, à définir ultérieurement ;
- source Search minimale pour SEO, sans transfert de ranking ni d'ownership.

Aucun consumer ne lit directement Aggregate, Repository, SQL, Runtime Health,
projection interne ou cache propriétaire.

## Indexabilité

Seul un résultat public positif explicite peut rendre un Listing candidat à
l'index. Un Listing non publié, retiré, expiré, suspendu, rejeté, archivé,
terminal, absent, corrompu ou dont la dépendance est indisponible est exclu en
fail-closed. Les noms exacts des états lifecycle restent internes.

## Conclusion

Une capacité Search autonome est certifiable. Les catalogues et contrats futurs
ne sont pas créés par cet audit.
