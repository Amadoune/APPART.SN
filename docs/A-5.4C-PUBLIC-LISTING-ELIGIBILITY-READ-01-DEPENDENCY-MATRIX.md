# A-5.4C Public Listing Eligibility Read — Dependency Matrix

| Producteur | Consommateur | Flux | Qualification |
|---|---|---|---|
| `ListingLifecycle` | future frontière publique | décision minimale par `ListingId` et instant | obligatoire, owner-local |
| future frontière publique | `Favorites` | résultat fermé | autorisé, read-only |
| `Favorites` | `FavoriteCollection` | commande locale après `Eligible` | hors audit, future |
| Public Projection | `Favorites` | reconstruction d'éligibilité | interdite |
| Search | `Favorites` | assimilation découvrabilité/éligibilité | interdite |
| Runtime Health | `Favorites` | décision métier | interdite |
| Listing Persistence / Aggregate | `Favorites` | lecture directe | interdite |
| Events / cache | `Favorites` | source de vérité | interdite |

La dépendance autorisée est unidirectionnelle :
`Favorites -> frontière publique ListingLifecycle`. Aucun retour vers Favorites,
aucune écriture cross-domain et aucun cycle ne sont admis.
