# Source authority

| Champ Public Media | Source owner | Révision disponible | Statut |
|---|---|---|---|
| mediaCollectionId | MediaCollection | collection v1 | disponible |
| mediaId | MediaItem | collection v1 | disponible |
| ordre | MediaItem.media_order | collection v1 | disponible |
| primary | MediaItem.is_primary | collection v1 | disponible |
| éligibilité domain | MediaItem.status + ingestion ready | collection v1 / asset v2 | disponible |
| URL publique | aucune | aucune | manquante |
| variants | aucune | aucune | non exigibles sans autorité |

La `storageKey` privée ne peut pas être promue en URL par convention.
