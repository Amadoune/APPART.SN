# Mutation catalog

Mutations metadata public-relevant existantes : MediaAdded, MediaRemoved, MediaArchived, MediaReordered, MediaMarkedPrimary; un changement de readiness/lifecycle de l'asset peut aussi modifier la livrabilité.

Le catalogue définitif doit ajouter les mutations propres à l'URL publique (activation, révocation, remplacement, expiration éventuelle). Elles sont inconnues tant que l'autorité préalable n'est pas rendue.
