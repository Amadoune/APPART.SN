# Media variants boundary

Le contrat accepte des variants mais n'en exige pas au moins un. Aucun pipeline productif original/thumbnail/card/gallery/webp n'est disponible dans les faits RC2.

La présente autorité n'autorise ni transformation ni variant inventé. Une galerie peut contractuellement porter une liste de variants vide, après qualification de l'URL principale par l'autorité préalable.
