# Public Media semantics

Le contrat représente une sélection ordonnée de médias publiquement livrables, avec une couverture désignée et une révision certifiant le payload. Il ne représente ni le binaire, ni un traitement d'image, ni la collection Media complète.

La sémantique de « publiquement livrable » reste incomplète tant qu'une autorité de delivery/URL n'existe pas.
