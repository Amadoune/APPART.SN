# Readiness handoff

Candidate Factory consomme `PublicMediaDecisionReader` via le `mediaCollectionId`. `Found` avec révision positive et couverture exploitable alimente la version Public Media; Missing/Corrupted ou cover absente maintient la readiness incomplète dans la source certifiée actuelle.

Après une future décision valide, `missing_public_media_version` doit disparaître. Aucun autre résultat Candidate n'est anticipé.
