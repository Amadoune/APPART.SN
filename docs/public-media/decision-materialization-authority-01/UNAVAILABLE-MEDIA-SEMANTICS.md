# Unavailable Media semantics

Removed et Archived cessent d'être actifs et ne peuvent rester primary. Ils doivent sortir d'une décision courante dérivée; l'historique demeure chez Media.

Le comportement d'une ressource binaire ready mais non publiquement livrable, révoquée ou expirée n'est pas qualifié. Il relève de Public Media Binary Delivery & URL Authority 01.
