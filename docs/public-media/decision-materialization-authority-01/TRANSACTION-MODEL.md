# Transaction model

La transaction est owner-locale Public Media et borne lecture de l'état courant, verrouillage, arbitrage monotone et write de décision. Aucune transaction distribuée ni write Listing, Property, Geography, ContentSeo, Search ou Projection.

Les faits source sont relus et leur révision validée; une mutation concurrente produit stale/retry, jamais une décision partielle.
