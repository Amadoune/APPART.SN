# Ownership

| Responsabilité | Owner |
|---|---|
| Binaire privé et asset readiness | Media / Media Ingestion |
| Collection, attachment, état | Media |
| Publication du Listing | Listing Lifecycle |
| Locator et décision de delivery | Media Public Delivery |
| Décision ordonnée Public Media | Public Media |
| Projection/page/SEO | consumers |

Media Public Delivery est l'unique owner final de la livraison. Public Projection ne participe jamais à l'autorisation.
