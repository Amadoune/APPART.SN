| Port V1 | Entrée | Résultats fermés |
|---|---|---|

## Règles

- interfaces Application V1 indépendantes de Laravel et PostgreSQL ;
- DTO immuables ;
- aucune exception technique ;
- aucun booléen comme résultat ;
- aucune exposition de store, snapshot, Aggregate, Repository ou état de
  persistence ;
- acteurs auto-scopés par le futur adapter HTTP ;
- visibilité et filtrage décidés par les readers owner-scoped ;
- résultat public anti-énumération pour la vue propre ;
- aucun contrat HTTP créé dans cet amendement.

## État

Ces contrats restent une spécification prête à implémenter. Leur création PHP
est suspendue : deux sources owner nécessaires ne sont pas autorisées dans le
périmètre actuel.
