# A-5.3-MODERATION-REPORT-OWNER-READ-SOURCE-01 — Runtime Binding

## Provider

`ModerationReportOwnerReadSourceServiceProvider` enregistre :

- le mapper en singleton ;
- l'autorité d'identité canonique en singleton ;
- l'adapter PostgreSQL en singleton ;
- un alias unique vers `ModerationReportOwnerReadSourceV1`.

Les singletons Laravel sont résolus paresseusement. Aucun fallback, Null Object
ou alias ambigu n'est enregistré.

## Garanties

- provider owner-scoped ;
- aucune extension Runtime Health ;
- aucune route ou composition HTTP ;
- aucune modification d'un provider 5.3 certifié ;
- résolution réelle par le container démontrée avec une connexion injectée.
