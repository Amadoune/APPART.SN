« Repository » désigne ici un futur rôle périphérique, jamais une classe présente. Treize Registries mutables définissent déjà une sauvegarde avec version attendue. `Product` est l’unique Root sans Registry mutable ni événement propre : décision obligatoire avant implémentation. Aucun test PostgreSQL, mapping, Outbox ou Dispatcher n’existe à cette baseline, puisque leurs implémentations n’existent pas.
