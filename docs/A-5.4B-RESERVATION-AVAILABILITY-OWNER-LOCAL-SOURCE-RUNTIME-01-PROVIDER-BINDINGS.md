# Provider et bindings

`ReservationAvailabilityOwnerSourceRuntimeServiceProvider` enregistre :

- le mapper et l'adapter PostgreSQL comme singletons internes ;
- l'alias unique de l'adapter vers `ReservationAvailabilityOwnerSource` ;
- la politique déterministe comme singleton et alias unique ;
- le Runtime déterministe comme singleton et alias public V1 unique.

Les résolutions sont lazy. Aucun Reader, Provider étranger ou Runtime Health
n'est composé.
