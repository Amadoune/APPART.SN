# ContentSeo Outbox Matrix

| Source | Statuts acceptés | Entrée Outbox |
|---|---|---|
| EditorialContentDeliveryV1 | Published, Unpublished, Missing, Corrupted, DependencyUnavailable | Exactement une |
| OperationalSeoDeliveryV1 | Indexable, NoIndex, Missing, Corrupted, DependencyUnavailable | Exactement une |

`messageId` dérive du payload canonique. Le checksum SHA-256 utilise un domaine
séparé. Une répétition identique retourne `AlreadyApplied`; une divergence retourne
`DivergentMessage`.
