# Application Persistence Contracts

`ConsentRevisionState` est immutable. Il valide une révision positive, des
instants UTC explicites avec `recordedAt >= effectiveAt` et une référence de
politique optionnelle minimale.

`ConsentOwnerSource` expose uniquement `append`, `at` et `history`.

Résultats d'écriture fermés : `Applied`, `AlreadyApplied`,
`DivergentRevision`, `VersionConflict`, `Corrupted`,
`DependencyUnavailable`.

Résultats de lecture fermés : `Found`, `Missing`, `Corrupted`,
`DependencyUnavailable`.

Le contrat public `LeadContactConsentReaderV1` reste inchangé et sans
implémentation dans ce jalon.
