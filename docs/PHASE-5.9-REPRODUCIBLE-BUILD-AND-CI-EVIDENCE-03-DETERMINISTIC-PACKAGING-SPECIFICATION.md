# Deterministic Packaging Specification

Le packaging doit partir exclusivement de R2, fixer ordre, timestamps, permissions, format et exclusions, puis produire deux archives comparables octet par octet.

Statut d'exécution : `BLOCKED`. Le script certifié dans R2 refuse R2 puisqu'il exige encore l'identité R1. Aucun packaging n'a été lancé.
