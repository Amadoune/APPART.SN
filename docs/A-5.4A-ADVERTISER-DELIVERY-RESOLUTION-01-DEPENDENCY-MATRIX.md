# A-5.4A — Advertiser Delivery Resolution — Dependency Matrix

| Dépendance | Qualification | Motif |
|---|---|---|
| Listing Contactability Reader V1 | obligatoire | aucune résolution si le Listing refuse une nouvelle intention |
| Listing contact principal boundary | obligatoire, absente | fournit légalement l'AccountId owner/délégué |
| Professional Mandate Resolver V1 | obligatoire et existante | résout AccountId vers ProfessionalId |
| Professional Public Status Reader V1 | obligatoire comme fait public | disponibilité professionnelle fail-closed |
| Professional lead-recipient permission | obligatoire, absente ou non certifiée | distingue disponibilité générale et droit de recevoir un Lead |
| IAM Account availability | facultative selon contrat Professional | ne doit pas être relue directement par ContactsLeads si Professional la possède déjà |
| Consent | obligatoire pour le parcours global, hors frontière | décision distincte |
| Anti-abus | obligatoire pour le parcours global, hors frontière | décision distincte |
| Notifications futures | facultative et hors frontière | canal/delivery ultérieurs |
| Public Projection | interdite | projection non autoritative |
| Search | interdite | finalité de découvrabilité |
| Listing Moderation | interdite | finalité de sanction |
| Historical Account | interdite | historique non autorité courante |
| SQL/Store/Repository cross-domain | interdite | contourne les frontières publiques |

## Flux candidat

```text
ListingId
  -> ListingContactabilityReaderV1
  -> Listing contact principal boundary
  -> ProfessionalMandateResolverV1
  -> Professional lead-recipient decision
  -> ContactsLeads eligibility
```

Chaque appel est read-only et fail-closed. Aucun appel ne partage une
transaction avec un autre owner.

## Cycles interdits

- Professional ne lit pas ContactsLeads pour décider le mandat ;
- ListingLifecycle ne lit pas Professional pour décider l'ownership ;
- ContactsLeads ne réécrit ni ownership Listing ni mandat Professional ;
- un résultat de delivery ne devient pas une source d'autorisation future.
