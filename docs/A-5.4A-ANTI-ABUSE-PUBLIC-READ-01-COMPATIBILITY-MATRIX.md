# Anti-abuse Compatibility Matrix

| Capacité | Compatibilité requise |
|---|---|
| Lead historique | aucune modification de l'Aggregate ou de sa déduplication |
| migrations 022–024 | inchangées |
| Contracts Foundation 5.4A | réutilisation de `LeadIngressIntentId`, aucun contrat modifié |
| chaîne Consent gelée | aucune dépendance ni modification |
| Listing et Professional | décisions indépendantes inchangées |
| Runtime et HTTP | aucune ouverture |
| Event, Delivery, Outbox | aucune ouverture |
| Phase 5.3 gelée | aucun impact |

Une future Persistence additive peut être owner-locale sans modifier les
capacités historiques, sous réserve d'une décision d'autorité distincte.
