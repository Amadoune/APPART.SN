# IAM Web Entry — Certification Note

## Décision proposée

Le parcours public compose les capacités IAM déjà certifiées sans élargir leur responsabilité. L’utilisateur dispose d’une entrée Web réelle, accessible et responsive. Le login, la conservation de session, le logout et le refus post-logout sont démontrés sur `https://appart.test` avec PostgreSQL local et le principal F3 certifié.

Toutes les gates ciblées du sprint sont terminales et PASS. Aucun mock, aucune session injectée, aucun SQL direct et aucune modification de politique IAM n’ont été introduits.
