# Public Search Filterable Read Model 01 — Certification Note

## Verdict

Le GO ne peut pas être proposé.

La cause racine unique est l'absence de la transaction dans toute source publique déjà intégrée à la projection certifiée. La valeur existe uniquement dans l'état de draft Authoring, dont la relecture est interdite par le périmètre. Sans décision d'autorité sur son transport vers la projection publique, Acheter/Louer ne peut pas être filtré avant pagination.

Ville et type ne sont pas implémentés isolément : cela laisserait le contrat demandé incomplet et ne satisferait pas les critères de certification.

## Décision proposée

**NO GO PROPOSÉ — APPART.SN PRODUCT AMENDMENT — PUBLIC SEARCH FILTERABLE READ MODEL 01**
