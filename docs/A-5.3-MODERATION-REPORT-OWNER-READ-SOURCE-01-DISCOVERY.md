# A-5.3-MODERATION-REPORT-OWNER-READ-SOURCE-01 — Discovery

## Statut

DISCOVERY GO CERTIFIÉ — FERMÉ

## Objet

Déterminer une source owner-scoped et read-only capable de résoudre un
`reportId` sans créer Query, Reader HTTP, Runtime, binding ou migration.

## Découverte principale

La résolution déterministe existe déjà dans l'écriture certifiée :

```text
caseId = deterministicUuid("moderation-case-v1", reportId)
```

`DeterministicModerationCaseOrchestratorV1::submit()` utilise exactement cette
règle avant de sauvegarder le dossier. `CanonicalModerationCommand` expose
l'algorithme déterministe SHA-256/UUID utilisé.

La résolution future peut donc :

1. valider le format de `reportId` ;
2. recalculer le `caseId` canonique ;
3. lire le dossier par sa clé primaire via la frontière owner-local ;
4. vérifier qu'une révision courante portant exactement ce `reportId` existe ;
5. extraire uniquement l'identité reporter nécessaire au contrôle d'ownership ;
6. retourner un résultat fermé sans exposer le snapshot.

## Résultats conceptuels de la source

- `Found(caseId, reporterAccountId, publicStateInputs)` ;
- `Missing` ;
- `Corrupted` ;
- `DependencyUnavailable`.

Ces résultats sont documentaires. Aucun port PHP ou DTO n'est créé pendant ce
Discovery.

## Déterminisme et confidentialité

- aucun scan de `report_revisions` ;
- aucune recherche cross-domain ;
- aucune reconstruction depuis Events ;
- aucune exposition des constats, décisions, preuves, intents ou checksums ;
- aucune confirmation d'ownership dans la source elle-même ;
- la future Query `ReadOwnModerationReportV1` restera responsable de convertir
  toute non-appartenance en `NotVisible`.

## Impact

- migrations 063–069 : aucun changement ;
- index PostgreSQL : aucun ajout ;
- Runtime, Commands, Events, Delivery, Outbox et 5.3I : aucun changement ;
- HTTP : absent ;
- transaction : aucune, lecture seule par clé primaire.

## Décision d'autorité

**GO CERTIFIÉ — FERMÉ.**

Une source additive est réalisable sans violation des fondations certifiées.
La prochaine étape autorisable après décision d'autorité est la Contracts &
Implementation Foundation de cette source uniquement. La source Queue reste
NON OUVERTE.
