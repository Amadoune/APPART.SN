# Professional Status Event Catalog Specification

| Transition | Type événementiel |
|---|---|
| `Active → Suspend → Suspended` | `professional.status.suspended` |
| `Suspended → Reactivate → Active` | `professional.status.reactivated` |

Le catalogue est fermé. Toute transition non certifiée est refusée explicitement. Aucun `ProfessionalRegistered` n'est produit par le cycle de statut.
