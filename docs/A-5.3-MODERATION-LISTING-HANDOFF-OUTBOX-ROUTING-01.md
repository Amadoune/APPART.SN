# A-5.3-MODERATION-LISTING-HANDOFF-OUTBOX-ROUTING-01

## Statut

AMENDEMENT OUVERT — REPRÉSENTATION GO PROPOSÉE

## Extension du routing

La destination statique owner-local suivante est ajoutée :

`moderation.listing-handoff`

Elle est produite exclusivement pour :

`moderation.decision.issued.v1`

Les quatre autres Events V1 ne sont jamais routés vers cette destination. Le
routeur reste statique, déterministe, fermé et sans résolution de domaine
externe.

## Claim filtré

`ModerationOutboxReaderV1` expose additivement :

```text
claimNextForDestination(owner, destination, now)
```

La signature historique suivante reste inchangée :

```text
claimNext(owner, now)
```

L'implémentation PostgreSQL applique le filtre dans la requête owner-local avant
`FOR UPDATE SKIP LOCKED`. Un worker Listing ne réclame donc jamais une livraison
Queue, Timeline ou Delivery Observation.

## Garanties conservées

Le claim filtré réutilise les mécanismes certifiés :

- ordre déterministe ;
- claim concurrent par `FOR UPDATE SKIP LOCKED` ;
- lease de trente secondes ;
- reprise d'une lease expirée ;
- release et retry ;
- replay ;
- delivery et quarantaine ;
- contrôle du claim owner.

Les opérations restent attachées à la livraison identifiée par
`messageId + destination`.

## Compatibilité historique

`claimNext(owner, now)` délègue au même mécanisme sans filtre. Son ordre et sa
sémantique restent inchangés.

Les destinations historiques restent :

- `moderation.queue` ;
- `moderation.timeline` ;
- `moderation.delivery-observation`.

Aucun consumer historique n'est reconfiguré.

## Events et identités

L'extension ne modifie pas :

- `ModerationEventV1` ;
- `ModerationDeliveryMessageV1` ;
- payload ;
- `eventId` ;
- checksum ;
- `messageId` ;
- correlationId ou causationId.

Une preuve de non-régression fixe les identités canoniques antérieures à
l'amendement.

## Migration

Aucune migration n'est nécessaire.

La colonne certifiée par 067 est :

```sql
destination varchar(64) NOT NULL
```

Elle ne possède aucune contrainte fermant le catalogue des valeurs. La nouvelle
destination compte 26 caractères et tient dans la dimension existante.

Les migrations 063 à 068 restent inchangées.

## Hors périmètre

L'amendement ne crée aucun :

- consumer Listing ;
- handoff métier ;
- appel IAM ou Listing ;
- Runtime 5.3I ;
- HTTP ;
- Event V1 ;
- Outbox supplémentaire ;
- migration.

La Phase 5.3I demeure fermée jusqu'à une décision explicite de reprise.
