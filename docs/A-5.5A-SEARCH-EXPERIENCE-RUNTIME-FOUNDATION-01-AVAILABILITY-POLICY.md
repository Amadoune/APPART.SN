# Availability Policy

| Source owner-locale | Runtime |
|---|---|
| `Found` | `Available` |
| `Missing` | `Available` |
| `Corrupted` | `Corrupted` |
| `DependencyUnavailable` | `DependencyUnavailable` |
| exception technique | `DependencyUnavailable` |

La sonde utilise une identité technique réservée et un instant explicite. Elle
ne transforme jamais un état Search en décision métier.
