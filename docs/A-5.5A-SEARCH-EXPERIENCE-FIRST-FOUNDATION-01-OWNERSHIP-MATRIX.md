# A-5.5A Search Experience First Foundation — Ownership Matrix

| Élément | Owner | Responsabilité | Interdit aux autres owners |
|---|---|---|---|
| décision d'indexabilité Listing | ListingLifecycle | fait public minimal | ranking et écriture Search |
| faits Property | RealEstateCatalog | éligibilité structurelle publique | mutation Search |
| faits Media | Media owner | readiness publique | mutation Search |
| décision Search finale | SearchDiscovery | visibilité, rank et facettes internes | recalcul consumer |
| journal Search | SearchDiscovery | historique autoritatif owner-local | SQL cross-domain |
| index courant Search | SearchDiscovery | lecture et API futures | autorité lifecycle |
| API Search | Search Experience | exposition future | accès Persistence direct |
| décisions SEO | ContentSeo | indexation SEO/canonical | pilotage Search |

`SearchDiscovery` est l'owner interne de Search Experience, pas une capacité
distincte. Aucun ownership n'est partagé.
