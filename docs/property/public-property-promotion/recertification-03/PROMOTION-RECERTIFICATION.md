# F7 — Recertification terminale de la promotion publique

## Objet

Cette campagne reprend au point « Property already exists » et requalifie sans correction produit la chaîne Authoring → Promotion → Submit.

## Résultat

La matrice est fermée : Property absente produit `Applied`; replay ledger identique et Property ledgerless canonique produisent `AlreadyApplied`; checksum divergent ou Property ledgerless incompatible produisent `DivergentCommand`.

Les refus Geography, les défaillances techniques, l’atomicité F6, l’atomicité Listing F7-A et le retry complet sont également recertifiés.

## Gouvernance

Les deux NO GO historiques restent conservés. Ils sont clos respectivement par F7-A et F7-B. Aucun code, test, Provider, store ou migration n’a été modifié dans cette recertification.
