# Rapport de compatibilité

Les autorités F0/F1, F2, F3, F4/F4-A et F5-A sont réutilisées sans modification. `Address::equals()`, ChangeAddress, RegisterProperty, PropertyTypePolicy, Submit et la migration 100 restent inchangés pendant la recertification.

L’audit récursif de l’application Promotion ne révèle aucune dépendance vers Projection, Search, Public Listing ou HTTP Geography. La source Geography demeure le Catalog applicatif F5-A.

Aucun backfill, migration 101, nouvelle règle Domain ou changement de contrat n’est introduit. Les données historiques restent compatibles avec les règles certifiées F6/F7-A/F7-B.
