# Certification

La Foundation matérialise le port Application, le mapper, l'adapter PostgreSQL
et la migration additive 076. Le journal est append-only, l'index est dérivé,
les écritures sont atomiques et les lectures temporelles sont fail-closed.

Le périmètre n'introduit aucun Runtime, Runtime Read, Reader, Provider, HTTP,
Event, Delivery ou Outbox et ne modifie aucune baseline gelée.
