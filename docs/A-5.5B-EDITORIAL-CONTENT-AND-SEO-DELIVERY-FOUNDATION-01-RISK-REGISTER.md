# ContentSeo Delivery Risk Register

| Risque | Maîtrise |
|---|---|
| Décision métier dans Delivery | Propagation bijective des Events V1 |
| Source non autorisée | Paramètre unique Event V1 correspondant |
| Perte de type ou d'instant | Payload canonique type/statut/observedAt |
| Fallback | Match exhaustif sans valeur par défaut |
| Couplage Infrastructure | Contrôle Architecture ciblé |
| Transport implicite | Aucun Provider, Routing, Outbox ou Consumer |
