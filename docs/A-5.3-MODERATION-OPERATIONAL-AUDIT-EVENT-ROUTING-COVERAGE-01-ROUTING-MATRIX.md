# A-5.3 — Operational Audit Event Routing Matrix

| Event V1 audité | Routes historiques préservées | Route additive contractuelle |
|---|---|---|
| `moderation.report.submitted.v1` | `moderation.queue`, `moderation.timeline` | `moderation.delivery-observation` |
| `moderation.report.validated.v1` | `moderation.queue`, `moderation.timeline` | `moderation.delivery-observation` |
| `moderation.finding.recorded.v1` | aucune | `moderation.delivery-observation` |
| `moderation.queue-item.claimed.v1` | aucune | `moderation.delivery-observation` |

## Réservations d'owner

- `moderation.queue` reste réservée à la projection Queue ;
- `moderation.timeline` reste réservée à la timeline du dossier ;
- `moderation.listing-handoff` reste réservée au handoff Listing ;
- `moderation.delivery-observation` reste owner ModerationReports et constitue
  la seule destination contractuelle de l'audit opérationnel.

Aucune destination dynamique ou externe n'est admise. Tout type ou destination
inconnu reste fail-closed.
