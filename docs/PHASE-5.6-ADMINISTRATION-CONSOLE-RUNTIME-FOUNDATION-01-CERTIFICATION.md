# Certification

La Runtime expose le catalogue fermé `Available`, `Corrupted`, `DependencyUnavailable`. Les diagnostics contiennent exclusivement le Runtime ID `administration-console.owner-source`, la version `administration-console-runtime-v1` et la disponibilité.

La certification est proposée après PASS des campagnes Unit, Feature composition, Architecture, PostgreSQL Runtime, PHPStan, Pint et `git diff --check`.
