# A-5.2B-MEDIA-ATTACHMENT-BOUNDARY-01 — Amendment

## Statut

**GO CERTIFIÉ — FERMÉ.**

## Cible protégée

F-06 Media Item Lifecycle, `MediaCollection`, `MediaItem`, migrations 004/007/
031/032, Event V1, Runtime, HTTP, Delivery et Outbox.

## Besoin

Media Ingestion doit rattacher un Asset Ready sans appeler les classes
concrètes `CreateMediaCollection` ou `AddMedia` et sans accéder à
`MediaCollectionRegistry`.

## Extension additive autorisable

Une future frontière Application publique :

`AttachReadyMediaAssetV1`

avec commande V1, résultat fermé, intentId/checksum et journal d’intents Media
owner-scoped. Elle compose uniquement les invariants déjà présents de F-06.
