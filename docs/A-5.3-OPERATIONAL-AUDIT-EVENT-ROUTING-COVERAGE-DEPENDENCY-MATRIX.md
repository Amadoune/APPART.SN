# A-5.3 — Operational Audit Event & Routing Coverage — Dependency Matrix

| Parcours | Event V1 | Production durable démontrée | Route Audit | Destination réutilisable | Décision |
|---|---|---:|---:|---|---|
| ReportSubmitted | oui | non | non | `delivery-observation` après amendement | amendement requis |
| ReportValidated | oui | non | non | `delivery-observation` après amendement | amendement requis |
| FindingRecorded | non | non | non | aucune avant création V1 | amendement requis |
| QueueItemClaimed | non | non | non | aucune avant création V1 | amendement requis |

## Impacts par capacité

| Capacité | Impact autorisable | Impact interdit |
|---|---|---|
| Event Catalog V1 | deux types additifs | réinterprétation des types existants |
| Orchestration 5.3F | composition additive après `Applied` | changement de résultats ou d'invariants |
| Routing 5.3G | routes additives vers `delivery-observation` | suppression ou détournement de routes |
| Delivery 5.3G | compatibilité et non-régression | nouvelle sémantique de Delivery |
| Outbox 5.3H | destinations additives issues du routeur | modification des identités/checksums existants |
| Handoff 5.3I | recertification d'impact | modification du consumer Listing |
| AdministrationAudit | aucune modification | contrat, persistence ou transaction partagée |
| HTTP 5.3J | aucune modification | émission directe depuis les Controllers |

## Dépendances préservées

- les Commands V1 restent inchangées ;
- les résultats métier restent fermés et indépendants ;
- les transactions demeurent owner-locales ;
- aucun consumer Audit n'accède directement à SQL ou aux stores
  AdministrationAudit ;
- les destinations Queue, Timeline et Listing Handoff conservent leur owner et
  leur consumer ;
- 5.3L reste non ouvert.

## Séquence normative proposée

1. décision d'autorité sur l'ouverture de l'amendement ;
2. Contracts/Event extension strictement additive ;
3. composition atomique et routing ;
4. recertifications ciblées 5.3F à 5.3I ;
5. reprise de 5.3K ;
6. aucune ouverture automatique de 5.3L.
