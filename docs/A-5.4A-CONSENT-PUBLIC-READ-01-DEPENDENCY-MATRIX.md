## Source durable

La preuve de consentement existe durablement dans le Lead historique.
L'audit n'a toutefois pas démontré une résolution préalable certifiée par
`LeadIngressIntentId`. Cette lacune :

- ne bloque pas la définition documentaire du contrat ;
- bloque toute implémentation tant qu'une source owner-locale n'est pas
  explicitement auditée et autorisée ;
- ne justifie aucune migration dans le présent amendement.

## Cycles interdits

- ContactsLeads → IdentityAccess → ContactsLeads pour décider le consentement ;
- Reader Consent → Anti-abus → Reader Consent ;
- Event ou projection → reconstruction de la preuve ;
- HTTP ou Runtime → source de vérité ;
- résultat `Granted` → acceptation composite automatique.
