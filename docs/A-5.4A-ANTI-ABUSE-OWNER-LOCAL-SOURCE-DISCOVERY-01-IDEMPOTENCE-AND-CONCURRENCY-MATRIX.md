# Anti-abuse Owner-local Source — Idempotence and Concurrency Matrix

| Cas | Résultat conceptuel |
|---|---|
| même intent, révision et checksum | `AlreadyApplied` |
| même intent et révision, checksum différent | divergence fail-closed |
| première révision différente de 1 | conflit de version |
| révision différente de `current + 1` | conflit de version |
| deux appends identiques concurrents | un `Applied`, un `AlreadyApplied` |
| deux appends divergents concurrents | un `Applied`, un divergent |
| erreur pendant append | rollback owner-local intégral |

Le checksum couvre canoniquement tous les champs persistés. Une transaction
locale et un savepoint en transaction englobante seront requis. Aucune
transaction distribuée.
