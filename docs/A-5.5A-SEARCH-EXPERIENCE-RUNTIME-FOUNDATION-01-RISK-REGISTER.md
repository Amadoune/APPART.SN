# Risk Register

| Risque | Maîtrise |
|---|---|
| Runtime utilisé comme décision métier | catalogue de disponibilité uniquement |
| fuite de données Search | diagnostics limités à id, version, disponibilité |
| fuite PostgreSQL | exceptions réduites à `DependencyUnavailable` |
| couplage Infrastructure | politique dépendant seulement du port Application |
| binding concurrent | alias uniques et singletons lazy |
