# A-5.3-GLOBAL-PROOF-QUALIFICATION — Risk Assessment

| Risque | Qualification | Impact | Traitement |
|---|---|---|---|
| timeout PostgreSQL masquant une régression | non démontré | élevé | campagne complète terminale obligatoire |
| timeout causé par infrastructure/workers | plausible | moyen | diagnostic d'environnement séparé |
| considérer le ciblé comme preuve globale | violation de gouvernance | élevé | interdit |
| corriger 5.3G dans l'amendement Report | mutation implicite d'une capacité gelée | critique | amendement 5.3G préalable |
| accepter Pint rouge par simple réserve | divergence de baseline | élevé | dérogation versionnée requise |
| retarder le GO Report | coût de calendrier | faible | statut conforme conservé |
| ouvrir Queue ou HTTP malgré la suspension | rupture de séquence | critique | maintenir NON OUVERT |

## Attribution

- PostgreSQL complet : blocage probatoire/global, cause exacte non qualifiée ;
- Pint : défaut de formatage réel mais hors périmètre Report, localisé en 5.3G ;
- source Report : aucune régression ciblée démontrée.

## Réserve officielle

Une réserve peut enregistrer que le défaut Pint n'appartient pas à Report. Elle
ne suffit pas à certifier Report tant que la règle « Pint obligatoirement vert »
reste normative.

## Verdict de risque

Maintenir le GO non proposable est le choix le moins risqué et le seul conforme
à la baseline actuelle. La prochaine décision doit porter exclusivement sur :

1. l'autorisation d'un diagnostic/rejeu PostgreSQL global ;
2. l'ouverture éventuelle d'un amendement 5.3G de formatage ou d'une dérogation
   de gouvernance versionnée.
