# Idempotence and Concurrency Matrix

| Cas | Résultat |
|---|---|
| même intent, révision et checksum | `AlreadyApplied` |
| même intent/révision, checksum différent | `DivergentRevision` |
| révision différente de `current + 1` | `VersionConflict` |
| premier append valide | `Applied` |
| deux processus, même première révision | un `Applied`, un `AlreadyApplied` |
| erreur dans transaction locale | rollback intégral |
| transaction englobante | savepoint owner-local |

La contrainte primaire sérialise la première insertion. Les révisions suivantes
verrouillent uniquement la série owner-locale. Aucun advisory lock n'est requis.
