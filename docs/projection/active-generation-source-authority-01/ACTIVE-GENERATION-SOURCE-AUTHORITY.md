# Active Generation Source Authority 01

## Décision

L'owner normatif est **Public Projection**. Une génération est l'epoch global d'un read model public cohérent. `ActiveGenerationReader` ne crée rien: il expose l'unique génération durable dont l'état est `active`.

Le store, le reader, le manager, le validator et le rebuild existent. En revanche, aucune autorité générique certifiée ne choisit l'identité d'une génération initiale ni ne déclenche son bootstrap. Cette décision préalable manque; le verdict est donc **NO GO PROPOSÉ**.
