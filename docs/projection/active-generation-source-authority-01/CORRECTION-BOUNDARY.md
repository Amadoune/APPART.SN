# Correction Boundary

Prochain chantier minimal requis: **Active Generation Bootstrap Authority 01**.

Il doit décider la source de `generationId`, l'acteur/opérateur autorisé, le scope local/production, l'identité de commande et la preuve d'exécution. Après cette décision seulement, une implémentation pourra composer Manager, Rebuilder et Validator sans nouvelle règle implicite.
