# Identity Model

`PublicProjectionGenerationId` accepte un UUID canonique minuscule versions 1 à 5. L'identité est stable pendant create/rebuild/validate/activate/replay. Le repository ne contient aucune policy de dérivation, aucun générateur et aucun contrat opérateur définissant l'identité initiale. Une valeur arbitraire est donc interdite par le présent gate.
