# Bootstrap Audit

Une Active est un prérequis du chemin runtime normal qui n'accepte pas explicitement une Candidate. La migration crée uniquement la structure. Aucun bootstrap de déploiement, commande générique, configuration ou initialisation runtime ne matérialise l'Active initiale.

`appart:local:first-listing` contient un scénario P02 local avec une constante de génération et le cycle complet, mais il est couplé à la création P02 et ne constitue pas une autorité générique de bootstrap RC2.
