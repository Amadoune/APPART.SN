# Bootstrap Semantics

Le bootstrap initial transforme un environnement sans Active en un read model public minimal, validé et actif. Créer une Candidate n'est pas activer; reconstruire la Candidate n'est pas la rendre visible. Une Active existante signifie que le bootstrap initial est terminé. Les générations suivantes relèvent d'un rebuild/cutover, même si elles réutilisent Manager, Validator et états.
