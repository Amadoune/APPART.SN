# RC2 Generation Identity

GenerationId réservé documentairement pour le bootstrap local RC2:

`da5484c1-a351-4683-9881-79f34c51197f`

Il a été produit une fois comme UUIDv4 par le générateur système après adoption de la présente policy. Il n'est ni persisté ni actif à ce stade. L'implémentation devra exiger cette valeur explicitement; tout replay RC2 réutilisera exactement la même identité.
