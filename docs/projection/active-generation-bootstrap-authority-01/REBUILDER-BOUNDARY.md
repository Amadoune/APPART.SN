# Rebuilder Boundary

Le Rebuilder est obligatoire ici parce que l'activation vide est interdite et qu'aucune projection n'existe. Il reçoit la Candidate et un scope de Listings explicite, assemble via les sources certifiées et écrit avec le writer candidat. Il ne crée ni n'active la génération. Pour les rebuilds futurs, le même composant peut traiter Full/Range/Listings avec checkpoints.
