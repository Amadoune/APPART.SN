# Title / Description Authority

Le draft RC2 contient un titre et une description réels. Ils appartiennent à Listing Authoring et ne doivent pas être reconstruits depuis l’UI ou Public Projection.

`ListingSeoSource` exige ces deux chaînes ; `ListingSeoDecisionPolicy` dérive le titre final en ajoutant ` | APPART.SN` et valide la meta description.

Il manque cependant un reader owner-scoped ContentSeo productif qui transporte ces faits Authoring jusqu’au snapshot. Cette lacune est une composition à qualifier, pas une permission de recopier SQL dans ContentSeo Application.
