# Ownership Model

- ContentSeo possède snapshot, canonical, historique, règles SEO et décision temporelle.
- ListingLifecycle possède état Published, révision, publication et expiration.
- Listing Authoring possède le titre et la description saisis.
- Property possède disponibilité et type ; Geography possède le lieu.
- SearchDiscovery possède la visibilité Search et sa révision.
- Media possède collection et média primaire.
- Public Projection consomme seulement les décisions ; elle n’en fabrique aucune.
- PublicationReview ne peut pas écrire directement un snapshot ContentSeo.
