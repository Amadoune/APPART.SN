# Normal Materialization Order

L’ordre d’assemblage réel est : Listing → Property → Media → Search → ContentSeo snapshot → Active Generation → DecisionTime → Public Geography → Public Media → Projection.

Pour la matérialisation amont, Search et ContentSeo peuvent être produits indépendamment après Published puis rejoindre la barrière de readiness Projection. L’option normative candidate est donc C, sans dépendance ContentSeo vers Search UX ou Projection.

Le séquencement exact du handoff et des replays doit être fermé par la prochaine Authority.
