# Correction Boundary

Prochain chantier minimal : **ContentSeo Snapshot Materialization Authority 01**.

Il devra décider exclusivement :

- readers owner pour Listing/Authoring, Search et Property/Geography ;
- autorité du canonical path ;
- snapshotId déterministe ;
- version et cohérence des révisions ;
- decisionAt stable ;
- handoff Published et catch-up communs.

Après GO de cette Authority seulement, une implémentation pourra composer le writer existant.
