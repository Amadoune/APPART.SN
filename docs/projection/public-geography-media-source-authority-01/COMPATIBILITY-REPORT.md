# Compatibility report

La décision préserve Listing Lifecycle, Property, Geography, Media, Search, ContentSeo, Public Projection et ActiveGeneration. Les contrats reader et les schémas restent inchangés.

Les prochaines capacités seront additives, owner-scoped, idempotentes et séparées. Aucun SQL Application, fallback legacy, transaction distribuée, UI/Search ou exécution Projection n'est autorisé.
