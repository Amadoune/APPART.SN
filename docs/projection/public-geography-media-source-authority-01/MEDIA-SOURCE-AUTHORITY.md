# Media source authority

Inputs owner nécessaires : collection par `mediaCollectionId`, `propertyId`, version et timestamp; items, ordre, statut, principal, checksum et disponibilité binaire; résolution d'URL/variantes publiques par Media.

RC2 possède les faits de collection et d'item. La décision d'exposition publique, les URLs/variantes, la causalité et le handoff restent à qualifier par le gate Media.
