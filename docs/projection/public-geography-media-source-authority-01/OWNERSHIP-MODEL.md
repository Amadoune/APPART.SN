# Ownership model

| Décision | Owner normatif | Consommateur |
|---|---|---|
| Public Geography | Geography | Public Projection |
| Public Media | Media | Public Projection |

Le fait qu'une décision soit lue par Projection ne lui transfère pas son ownership. Listing Published peut déclencher un handoff, mais ne doit ni fabriquer les données Geography/Media ni partager leurs transactions.
