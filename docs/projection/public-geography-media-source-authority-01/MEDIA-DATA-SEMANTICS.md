# Media data semantics

La décision publique porte une collection, une couverture publique optionnelle et une galerie ordonnée. Chaque média possède identité, URL publique et variantes déjà décidées. La disponibilité owner (`active`, non removed, non archived), l'ordre et le principal alimentent la décision mais ne peuvent être redéduits par Projection.

Une couverture absente laisse la version Media indisponible pour la source de Projection actuelle.
