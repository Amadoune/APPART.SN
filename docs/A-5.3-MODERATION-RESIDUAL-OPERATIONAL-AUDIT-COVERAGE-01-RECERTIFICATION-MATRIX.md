# Recertification Matrix

| Fondation | Preuves futures requises | Invariants à préserver |
|---|---|---|
| 5.3F Orchestration | Unit, PostgreSQL ciblé, concurrence, rollback, savepoint | six Commands, quatre yeux, résultats fermés |
| 5.3G Event / Routing / Delivery | Unit, Architecture, Delivery, replay, divergence | Events V1 historiques byte-for-byte |
| 5.3H Atomic Outbox | PostgreSQL ciblé, atomicité, retry, quarantaine | Outbox owner-locale, aucun handoff direct |
| 5.3I Listing Handoff | Unit, PostgreSQL, concurrence, replay | frontières IAM/Listing seulement, transactions indépendantes |

La présente Contracts Foundation ne déclenche aucune de ces recertifications :
elle en fixe les gates pour une future décision d'implémentation.

## Exclusions

- aucun routing exécutable ;
- aucun consumer Audit ;
- aucun Provider ou binding ;
- aucune migration ou SQL ;
- aucune modification des Events V1 historiques ;
- aucune modification de 5.3F à 5.3I ;
- aucune reprise de 5.3K ;
- aucune ouverture de 5.3L.
