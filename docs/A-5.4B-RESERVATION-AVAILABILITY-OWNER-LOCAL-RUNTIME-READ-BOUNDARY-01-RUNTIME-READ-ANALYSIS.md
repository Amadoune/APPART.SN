# Runtime Read Analysis

## Point de lecture

La future lecture reçoit exclusivement l'intent, le sujet, la fenêtre et
l'instant d'observation contractuels déjà certifiés. Elle retourne un résultat
Runtime fermé : `Allowed`, `Conflicting`, `Missing`, `Corrupted` ou
`DependencyUnavailable`.

## Réduction

| Résultat owner-local | Résultat Runtime Read |
|---|---|
| `Available` | `Allowed` |
| `Conflicting` | `Conflicting` |
| `Missing` | `Missing` |
| `Corrupted` | `Corrupted` |
| `DependencyUnavailable` | `DependencyUnavailable` |

Restent internes : `ReservationAvailabilityRevisionState`, la décision de
révision, le checksum, la révision, les timestamps persistés et l'historique.

La Runtime Read porte la sélection temporelle et cette réduction uniquement.
Le futur Owner Reader adaptera mécaniquement le résultat Runtime vers le contrat
public, sans accéder à la Persistence.
