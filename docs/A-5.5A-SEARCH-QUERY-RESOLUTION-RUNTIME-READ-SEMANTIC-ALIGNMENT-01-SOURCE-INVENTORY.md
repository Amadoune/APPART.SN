# Source Inventory

- `SearchQueryResolutionReaderV1::read(SearchQuery, ObservedAt)` : contrat public.
- `SearchQueryResolutionOwnerSource::read(SearchQuery, ObservedAt)` : lecture
  owner-locale capable de distinguer les décisions persistées.
- `SearchQueryResolutionOwnerSourceRuntimeV1` : disponibilité technique seule.
- Runtime Read candidate : aucun argument, résultat `Found` dérivé de la santé.
- journal 076 : autorité durable owner-locale ; index 076 : dérivé.
- migration 076 : gelée et inchangée.
- projections, caches, Events et Runtime Health : non autoritatifs.

La requête brute, `SearchDocumentId`, `SearchIndexId` et `ListingId` ne doivent
traverser aucune frontière publique.
