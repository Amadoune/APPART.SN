# Runtime Read Policy

La Persistence sélectionne la révision applicable à l'instant observé. La
politique Runtime effectue uniquement la réduction suivante :

- `Found + Granted` → `Granted` ;
- `Found + Denied|Undecided|Withdrawn` → `Denied` ;
- `Missing` → `Missing` ;
- `Corrupted` → `Corrupted` ;
- `DependencyUnavailable` ou exception inattendue → `DependencyUnavailable`.

Cette réduction est déterministe et fail-closed. Elle n'ajoute aucune règle
de consentement et ne consulte ni Runtime Health ni une autre autorité.
