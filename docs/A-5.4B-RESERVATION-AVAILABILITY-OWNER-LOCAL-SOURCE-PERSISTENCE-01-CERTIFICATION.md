# A-5.4B Reservation Availability Persistence — Certification

## Preuves attendues et produites

- Unit : états, mapper et checksum ;
- Architecture : Application indépendante et persistence owner-locale ;
- PostgreSQL : migration, rollback, append, temporalité, idempotence,
  divergence, conflit, corruption, transaction, savepoint et concurrence ;
- PHPStan, Pint et `git diff --check`.

## Périmètre préservé

Aucun Runtime, Runtime Read, Reader, Provider, binding, HTTP, Event, Delivery,
Outbox, cache, projection ou orchestration n'est créé. Aucun composant gelé
n'est modifié.

Le verdict proposé porte exclusivement sur la Persistence Foundation.
