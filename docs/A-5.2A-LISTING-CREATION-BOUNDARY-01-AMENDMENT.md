# A-5.2A-LISTING-CREATION-BOUNDARY-01 — Amendment

## Statut

```text
A-5.2A-LISTING-CREATION-BOUNDARY-01
→ GO CERTIFIÉ
→ FERMÉ
```

## Objet

Autoriser une frontière Application publique V1 pour la création initiale d'un
Listing, sans modifier la sémantique de Listing Publication Lifecycle F-01.

## Périmètre protégé

Restent inchangés :

- Aggregate `Listing`, états et transitions ;
- association immuable ListingId–PropertyId ;
- `ListingDraftCreated` historique et catalogues Event V1 certifiés ;
- tables `listing_lifecycle.listings` et `listing_revisions` ;
- migrations 001–054 ;
- optimistic locking et historique append-only ;
- Runtime, Runtime Health, HTTP, routing, delivery et Outbox ;
- F-02, F-11, F-14, F-15, F-17 et F-18.

## Extension autorisable après GO

- port Application `CreateListingDraftV1` ;
- Command et Result V1 fermés ;
- journal d'intents propriétaire Listing, additif ;
- transaction locale Listing regroupant intent, racine et première révision ;
- future migration additive postérieure à 054 ;
- adapter Infrastructure owner-scoped.

Le présent amendement ne crée aucun de ces composants.
