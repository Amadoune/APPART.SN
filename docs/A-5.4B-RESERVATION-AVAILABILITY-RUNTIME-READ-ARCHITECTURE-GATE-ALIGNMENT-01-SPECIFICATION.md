# Architecture Gate Alignment — Specification

L'ancienne gate interdisait globalement tout répertoire
`ReservationAvailabilityOwnerReader`. Cette assertion prospective est remplacée
par une admission strictement nominative de :

- `OwnerReservationAvailabilityReaderV1` ;
- `ReservationAvailabilityOwnerReaderServiceProvider` ;
- l'alias unique `ReservationAvailabilityReaderV1` vers le Reader owner.

Le Reader doit dépendre de `ReservationAvailabilityOwnerSourceRuntimeReadV1`.
Toutes les dépendances Persistence, Infrastructure et surfaces ultérieures
restent interdites.
