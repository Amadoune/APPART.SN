# Temporal Read Matrix

| Situation à l'instant observé | Résultat persistence | Réduction future |
|---|---|---|
| dernière révision `Granted` | `Found(Granted)` | `Granted` |
| `Undecided`, `Denied` ou `Withdrawn` | `Found(decision)` | `Denied` |
| aucune révision applicable | `Missing` | `Missing` |
| version, checksum ou chronologie incohérents | `Corrupted` | `Corrupted` |
| source inaccessible | `DependencyUnavailable` | `DependencyUnavailable` |

La sélection est la dernière révision dont `effective_at` est inférieur ou
égal à l'instant observé. Aucune horloge implicite n'est utilisée.
