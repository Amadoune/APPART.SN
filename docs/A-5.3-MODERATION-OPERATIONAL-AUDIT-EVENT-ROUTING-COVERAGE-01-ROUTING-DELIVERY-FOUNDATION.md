# A-5.3 — Operational Audit Routing & Delivery Integration Foundation

## Périmètre

Cette Foundation complète exclusivement la chaîne owner-local certifiée :

```text
Event V1 ModerationReports
→ Routing statique
→ Outbox Delivery
→ moderation.delivery-observation
→ consumer Audit
→ AdministrationAuditAppendV1
```

Elle ne rouvre ni 5.3K ni 5.3L.

## Matrice exécutable

| Event V1 | Routes historiques préservées | Route additive Audit |
|---|---|---|
| `moderation.report.submitted.v1` | `moderation.queue`, `moderation.timeline` | `moderation.delivery-observation` |
| `moderation.report.validated.v1` | `moderation.queue`, `moderation.timeline` | `moderation.delivery-observation` |
| `moderation.finding.recorded.v1` | aucune | `moderation.delivery-observation` |
| `moderation.queue-item.claimed.v1` | aucune | `moderation.delivery-observation` |

La matrice est fermée, déterministe et fail-closed. Aucune destination dynamique
ou externe n'est admise.

## Delivery et consumer

Les livraisons sont créées dans les tables Outbox certifiées, avec unicité
`message_id + destination`. Le message source reste immuable.

Le reader Audit :

- claim exclusivement `moderation.delivery-observation` ;
- valide le transport, l'identité Event, le messageId et le checksum ;
- place immédiatement en quarantaine tout transport corrompu ;
- conserve les politiques bornées de retry et de reprise.

Le consumer transforme mécaniquement les quatre Events autorisés en
`AdministrationAuditAppendV1`. Il ne consulte aucun Aggregate, Repository,
Event historique, SQL cross-domain ou donnée complémentaire.

## Transactions

Les transactions restent indépendantes :

1. claim ModerationReports puis commit ;
2. append AdministrationAudit puis commit ;
3. markDelivered ModerationReports puis commit.

Une indisponibilité Audit programme un retry et ne marque jamais la livraison
Delivered. Aucune transaction distribuée ni connexion partagée n'est créée.

## Confidentialité

La conversion utilise uniquement les champs contractuels fermés. Aucun texte
libre, rôle, rationale, preuve, URI, email, téléphone, adresse, IP, secret,
token ou diagnostic interne n'est exporté.

## Préservation

Restent inchangés :

- les six Commands et leurs résultats ;
- les quatre Queries ;
- la production Event et l'atomicité mutation–Outbox ;
- les migrations et schémas ;
- le consumer et le Gateway Listing ;
- IAM, Listing Eligibility et Runtime Health ;
- HTTP 5.3J ;
- `AdministrationAuditAppendV1` et sa persistence.
