# Consumer matrix

| Consumer | Besoin légitime |
|---|---|
| Public Projection | locality, breadcrumb public, version positive |
| ContentSeo | locality/breadcrumb quand fourni par la source Projection |
| Search | aucun accès direct Public Geography observé |
| Public Listing UI | breadcrumb livré par la projection |

Le payload minimal commun est la représentation identifiée/typée/labelisée, sans URL. La navigation cliquable éventuelle relève d'une autre authority produit.
