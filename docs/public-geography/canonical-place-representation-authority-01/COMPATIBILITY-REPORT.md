# Compatibility report

La décision préserve les identités et règles Geography, l'adressabilité Property, Listing Lifecycle, Search, ContentSeo et Projection. Elle n'ajoute ni route, slug, table ni canonical URL.

Incompatibilité connue et désormais explicite : le DTO historique breadcrumb impose une URL fictive. Son évolution additive/versionnée doit être qualifiée au reopening de Materialization Authority; aucune URL legacy ne sera conservée comme autorité.
