# Compatibility report

Le NO GO préserve intégralement Geography, Listing Lifecycle, Property, Search, ContentSeo, Public Projection et Media. Aucun contrat, route, provider, table ou donnée n'est modifié.

L'autorité préalable doit rester additive et Geography-owned. Elle ne doit ni créer de pages publiques implicitement, ni reprendre les URLs P02 comme règle de production.
