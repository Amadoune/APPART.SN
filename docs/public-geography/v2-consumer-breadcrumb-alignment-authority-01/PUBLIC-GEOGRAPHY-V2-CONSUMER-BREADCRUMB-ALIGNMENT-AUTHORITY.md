# Public Geography V2 Consumer Breadcrumb Alignment Authority 01

Public Geography V2 est la source normative et ne porte aucune URL. Les consumers adoptent un breadcrumb Geography informatif, root→leaf et non navigable. Le canonical Listing demeure séparé et inchangé.
