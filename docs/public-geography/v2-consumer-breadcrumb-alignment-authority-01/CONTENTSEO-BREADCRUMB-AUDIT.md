# ContentSeo breadcrumb audit

`ContentSeo\BreadcrumbItem` exige `label + CanonicalUrl` techniquement. `ListingSeoDecisionPolicy` concatène Geography items et un item Listing canonical.

L'URL Geography n'est pas utilisée pour décider canonical, robots, indexability ou structured data RealEstateListing. Seule la canonical Listing est normative. L'obligation URL est donc une structure V1 technique, pas une autorité Geography.
