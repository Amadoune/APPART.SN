# A-5.3-POSTGRESQL-FULL-CAMPAIGN-DIAGNOSTIC-01 — Certification Plan

## Décision recommandée

Autoriser une campagne PostgreSQL complète dédiée, sans modification du code.

## Préconditions

1. confirmer PostgreSQL 18.x et les trois variables d'environnement sans
   enregistrer leurs valeurs ;
2. inventorier les processus PHP et sessions PostgreSQL antérieurs ;
3. réserver une fenêtre nettement supérieure à 600 secondes ;
4. exécuter la commande officielle sans parallélisation improvisée ;
5. conserver stdout, stderr, durée et code de sortie.

Toute action de nettoyage ou d'arrêt de processus devra relever d'une décision
opérationnelle explicite ; elle n'est pas exécutée par ce diagnostic.

## Preuve recevable

Seul le résumé terminal PHPUnit est recevable :

```text
Tests: N
Assertions: N
Failures: 0
Errors: 0
Exit code: 0
```

Un nouveau timeout, une progression partielle ou des tests observés isolément
ne constituent pas un PASS.

## Suites selon résultat

- **PASS terminal** : représentation de la preuve PostgreSQL à l'autorité ;
- **FAIL terminal** : qualification indépendante de l'échec, sans correction
  implicite ;
- **nouveau timeout sans stagnation** : augmenter la fenêtre opérationnelle ;
- **stagnation démontrée** : identifier le test et les verrous avant toute
  proposition de correctif.

## Prochaine décision strictement autorisable

Autorisation opérationnelle d'une campagne PostgreSQL complète dédiée avec
fenêtre suffisante. Aucun amendement 5.3G, Queue, HTTP, 5.3K ou 5.3L n'est
ouvert.
