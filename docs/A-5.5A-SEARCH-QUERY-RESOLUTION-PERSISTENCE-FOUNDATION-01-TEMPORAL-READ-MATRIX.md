# Temporal Read Matrix

| Situation | Résultat |
|---|---|
| aucune révision observable | Missing |
| dernière décision observable `found` | Found |
| dernière décision observable `empty` | Empty |
| checksum ou chronologie invalide | Corrupted |
| dépendance indisponible | DependencyUnavailable |

Une révision n'est observable que si ses instants effectif et d'enregistrement
sont antérieurs ou égaux à l'instant explicite de lecture.
