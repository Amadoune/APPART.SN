# Availability Policy

| Source owner-locale | Runtime |
|---|---|
| `Found` | `Available` |
| `Missing` | `Available` |
| `Corrupted` | `Corrupted` |
| `DependencyUnavailable` | `DependencyUnavailable` |
| exception inattendue | `DependencyUnavailable` |

La sonde emploie une identité technique fixe et un instant explicite. Elle ne prend aucune décision anti-abus publique.
