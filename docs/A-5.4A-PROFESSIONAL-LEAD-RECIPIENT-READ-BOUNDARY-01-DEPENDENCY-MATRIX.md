# A-5.4A — Professional Lead Recipient — Dependency Matrix

| Dépendance | Qualification | Rôle |
|---|---|---|
| ProfessionalId | Obligatoire | identité opaque de la décision |
| Professional Status | Obligatoire | disponibilité publique owner-locale |
| Professional Profile / Verification | À qualifier | éventuels faits d'éligibilité |
| Professional Mandate | Facultative pour cette décision | résolution Account vers Professional en amont |
| Establishment | Interdite par défaut | aucune nécessité minimale démontrée |
| Professional Runtime | Interdite comme autorité | composition technique uniquement |
| Listing Contact Principal | Hors frontière | fournit éventuellement l'Account en amont |
| Consent | Hors frontière | owner distinct à qualifier |
| Anti-abus | Hors frontière | owner distinct à qualifier |
| Notifications | Hors frontière | canal et delivery futurs |
| ContactsLeads | Consumer futur, actuellement interdit | ne décide pas l'éligibilité Professional |

## Flux conceptuel futur

```text
ProfessionalId
    -> décision owner Professional
    -> résultat minimal fail-closed
```

Le flux ne doit lire aucun autre module, ni produire de transaction
cross-domain.

## Cycles interdits

- Professional ne consulte pas ContactsLeads pour décider son éligibilité ;
- Professional Status ne dépend pas d'un résultat de delivery ;
- Mandate ne dépend pas de Listing Contact Principal ;
- Runtime ne reconstruit pas une permission métier.
