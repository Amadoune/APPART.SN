# A-5.4B Reservation Availability Persistence — Temporal Read Matrix

| Cas | Résultat |
|---|---|
| intent absent à l'instant observé | `Missing` |
| intent cohérent, aucun autre état bloquant | `Available` |
| autre intent `Held` ou `Committed` chevauchant | `Conflicting` |
| sujet/fenêtre divergents | `Corrupted` |
| checksum ou chronologie invalide | `Corrupted` |
| PostgreSQL indisponible | `DependencyUnavailable` |

La lecture utilise uniquement les révisions dont `effectiveAt` et `recordedAt`
sont antérieurs ou égaux à l'instant observé. Les fenêtres sont semi-ouvertes.
