# Source Inventory

- `SearchQuery` : entrée publique opaque et déclarative.
- `SearchObservedAt` : instant public explicite.
- `SearchDocumentId` : créé par le flux interne d'indexation, porté par
  `SearchDocument`, `SearchIndex`, journal 075 et Runtime Read documentaire.
- `SearchIndexId` : identité interne de l'aggregate/index Search.
- journal 075 : vérité durable owner-locale, non exposée.
- index courant 075 : dérivé et non autoritatif.
- `public_search_decisions` historique : baseline gelée, non source de résolution.
- projections, caches et Events : non autoritatifs.

Aucune source existante ne résout une `SearchQuery`.
