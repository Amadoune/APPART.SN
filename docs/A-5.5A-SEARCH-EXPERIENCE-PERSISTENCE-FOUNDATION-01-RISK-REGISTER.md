# Risk Register

| Risque | Maîtrise |
|---|---|
| index pris comme autorité | journal seul autoritatif, index dérivé |
| divergence concurrente | verrou par document + révision monotone |
| double écriture partielle | transaction atomique et savepoint |
| corruption silencieuse | checksums payload et révision, lecture fail-closed |
| couplage cross-domain | aucune FK, port owner-local |
| fuite technique | catalogues fermés, aucune exception exposée |
