## Motif

Deux des quatre Queries ne disposent d'aucune source owner certifiée :

- `ReadOwnModerationReportV1` exige une résolution par `reportId` absente ;
- `ReadModerationQueueV1` exige une collection filtrée/paginée absente.

`ModerationCaseStore` et `ModerationDecisionStore` permettraient les deux autres
readers, mais une implémentation partielle est interdite.

- aucune modification des migrations 063–069 ;
- aucune modification de Runtime Health, des Commands, de l'orchestrateur,
  d'Event V1, Delivery, Outbox ou 5.3I ;

sources manquantes, ou de deux amendements séparés :

- `A-5.3-MODERATION-REPORT-OWNER-READ-SOURCE-01` ;
