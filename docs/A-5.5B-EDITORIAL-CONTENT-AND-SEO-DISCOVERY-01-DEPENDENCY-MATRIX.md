# Editorial Content & Operational SEO — Dependency Matrix

| Dépendance | Statut | Condition |
|---|---|---|
| Lecture publique Listing | Autorisée | Faits minimaux, owner `ListingLifecycle` |
| Lecture publique Media | Autorisée | Médias publics uniquement |
| Lecture publique Geography | Autorisée | Identité/libellé publics uniquement |
| Lecture publique Search | Conditionnelle | Contrat gelé, sans internals Search |
| Autorisation Identity | Conditionnelle | Décision opaque, aucune PII |
| Rendering | Sortante autorisée | Document public déjà décidé |
| Aggregate ou Persistence externe | Interdite | Violation d'ownership |
| Projection interne ou cache propriétaire | Interdite | Source non publique |
| Runtime Health | Interdite | Disponibilité technique non métier |
| Événements comme reconstruction d'autorité | Interdite | Duplication de décision |

Aucun cycle : les domaines sources ne dépendent pas de `ContentSeo` pour leurs
décisions métier. Rendering ne remonte aucune décision vers l'owner.
