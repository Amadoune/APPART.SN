# Place Lifecycle Event — Politique de confidentialité V1

## Données autorisées

- identités techniques `placeId` et, uniquement pour une fusion,
  `targetPlaceId`;
- états précédent et résultant;
- action;
- version résultante;
- instant métier UTC;
- identité déterministe et version du contrat.

## Données interdites

- acteur;
- identifiant d'intention;
- version observée de la cible;
- état observé de la cible;
- types observés;
- pays observés;
- preuve de qualification;
- données issues d'une projection ou d'un registre.

Le contrat publie le fait décidé, jamais les éléments internes ayant permis de
prendre la décision.
