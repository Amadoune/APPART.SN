# A-5.4A-CONSENT-PUBLIC-READ-01 — Contracts Amendment

## Statut

`OUVERT — CONTRACTUEL ET DOCUMENTAIRE UNIQUEMENT`

## Owner et responsabilité

La frontière appartient exclusivement à `ContactsLeads`. Elle exprime la
décision publique minimale :

> l'intention de contact identifiée dispose-t-elle, à l'instant observé, du
> consentement spécifique requis ?

Elle ne décide ni de la contactabilité du Listing, ni du principal Listing, ni
de l'éligibilité Professional, ni de l'anti-abus, ni de l'acceptation finale du
Lead Ingress.

## Reader V1 proposé

Forme conceptuelle, non exécutable :

```text
LeadContactConsentReaderV1::read(
    LeadIngressIntentId,
    LeadConsentObservedAt
): LeadContactConsentResultV1
```

Le Reader est :

- V1 ;
- read-only ;
- owner-scoped `ContactsLeads` ;
- déterministe pour une identité et un instant identiques ;
- fail-closed ;
- indépendant de Laravel, Runtime, HTTP et Persistence ;
- sans horloge implicite.

## Identité minimale

`LeadIngressIntentId` existant est réutilisé. Il identifie l'intention avant
son acceptation et évite de créer une nouvelle identité.

`LeadIngressId` n'est pas adapté à cette lecture préalable : il peut ne pas
encore exister au moment où le consentement doit être décidé.

## Value Object documentaire

`LeadConsentObservedAt` est le seul nouveau Value Object conceptuel :

- immutable et readonly ;
- instant explicite ;
- normalisé UTC ;
- représentation canonique `Y-m-dTH:i:s.uZ` ;
- aucune valeur par défaut et aucun appel implicite à `now()`.

Aucun fichier PHP n'est créé par cet amendement.

## Catalogue fermé

| Statut | Sémantique | Autorise la poursuite |
|---|---|---|
| `Granted` | consentement spécifique valable à l'instant observé | oui |
| `Denied` | consentement absent, refusé, retiré ou non valable | non |
| `Missing` | aucune intention ou décision owner-locale qualifiable | non |
| `Corrupted` | état owner incohérent | non |
| `DependencyUnavailable` | source owner indisponible | non |

Seul `Granted` autorise la poursuite. Le résultat ne contient aucune preuve,
version de texte, date d'acceptation, identité personnelle ou diagnostic.

## Catalogue d'erreurs publiques

Le catalogue documentaire maximal est :

- `InvalidRequest` ;
- `ConsentNotGranted` ;
- `NotFound` ;
- `DependencyUnavailable` ;
- `InternalFailure`.

Mapping normatif :

| Résultat | Erreur publique |
|---|---|
| `Granted` | aucune |
| `Denied` | `ConsentNotGranted` |
| `Missing` | `NotFound` |
| `Corrupted` | `InternalFailure` |
| `DependencyUnavailable` | `DependencyUnavailable` |

Ces erreurs ne constituent ni un contrat HTTP ni une autorisation de réponse
JSON. Aucun diagnostic interne ne les accompagne.

## Confidentialité

La frontière n'expose jamais :

- la preuve complète ;
- la finalité interne ou la version du texte accepté ;
- l'instant d'acceptation ou de retrait ;
- le contenu ou les coordonnées du Lead ;
- AccountId, ListingId, ProfessionalId ou identité visiteur ;
- Aggregate, Snapshot, version interne ou diagnostic ;
- décision anti-abus.

## Garanties de non-ouverture

Ce document ne crée aucune interface PHP, implémentation, source, migration,
Runtime, Provider, binding, HTTP, Event, Delivery, Outbox ou orchestration.
Il n'ouvre aucune Foundation ni l'amendement Anti-abus.
