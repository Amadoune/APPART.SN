# Risk Register

| Risque | Niveau | Mitigation documentaire |
|---|---|---|
| confusion Runtime / Runtime Read | élevé | façades séparées et responsabilités fermées |
| fuite de Persistence ou de State | élevé | résultat Runtime minimal sans état ni checksum |
| alias du port Persistence | élevé | aucune révision ou opération d'append exposée |
| duplication du Reader public | moyen | Runtime Read limitée à la réduction owner-locale |
| dépendance Reader vers Infrastructure | élevé | dépendance exclusive vers la future façade |
| dépendance circulaire | élevé | flux unidirectionnel imposé |
| modification d'une baseline gelée | élevé | Foundation additive indépendante |
| fuite de diagnostics | élevé | catalogue fermé sans détail technique |
