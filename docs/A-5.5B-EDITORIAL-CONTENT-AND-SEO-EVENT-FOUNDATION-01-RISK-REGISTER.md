# ContentSeo Event Risk Register

| Risque | Maîtrise |
|---|---|
| Décision métier dans Event | Réduction bijective des statuts publics |
| Source non autorisée | Dépendances limitées aux Readers publics V1 |
| Payload excessif | Statut et observedAt uniquement |
| Horloge implicite | Instant contractuel transmis et canonique |
| Couplage Infrastructure | Contrôle Architecture ciblé |
| Transport implicite | Aucun Provider, Routing, Delivery ou Consumer |
