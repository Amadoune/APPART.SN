# Provider and Bindings

Le Provider dédié enregistre la politique et la façade déterministes sous forme de singletons lazy et d'alias uniques. Il consomme seulement le port Application `AntiAbuseOwnerSource`, déjà composé par la Runtime Foundation certifiée.

Aucun adapter, mapper, PDO, Reader public, Runtime Health ou fallback n'est exposé.
