# Notifications HTTP Matrix

| Surface | 200 | 404 | 503 |
|---|---|---|---|
| Preference | Enabled, Disabled | Missing | Corrupted, DependencyUnavailable |
| Template | Available | Missing | Corrupted, DependencyUnavailable |
| Channel | Allowed, Blocked | Missing | Corrupted, DependencyUnavailable |

Les réponses contiennent uniquement `status`, avec `Cache-Control: no-store`.
