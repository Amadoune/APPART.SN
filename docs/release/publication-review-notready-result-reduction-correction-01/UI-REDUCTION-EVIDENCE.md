# UI Reduction Evidence

The Blade now has explicit `confirmed` and `not-ready` branches instead of treating every remaining mode as success.

For `NotReady`, it displays:

- “Publication en cours”;
- “L’annonce n’est pas encore prête.”;
- “Le traitement de publication n’a pas abouti. Réessayez plus tard depuis la file de publication.”

It does not display “Publication confirmée”, “L’annonce est maintenant publique” or a link claiming successful public availability.
