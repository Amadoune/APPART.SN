# Successor Identity Model

Modèle non circulaire :

- predecessor connu : commit RC2-R2 `6fc2f7944368c65f0cd87dfa68f550faa3461be9` ;
- futur tag symbolique exact : `appart-sn-release-candidate-rc2-r3` ;
- aucun SHA/tree RC2-R3 futur dans son propre contenu ;
- après matérialisation, le tag annoté devra résoudre exactement vers le nouveau HEAD.

Le modèle est identique aux successions R4→R5 et RC2→RC2-R2.
