# Reproducible Build Replay Model

Les preuves RC2-R2 acquises restent historiques : Identity PASS, Composer restore PASS, npm restore PASS et Unit PASS.

Après correction et matérialisation RC2-R3, la campagne doit repartir de zéro : identité, fresh restore, frontend build, puis toutes les suites. Aucun résultat RC2-R2 ne peut être recyclé comme PASS RC2-R3 et la reprise directe à Feature est interdite.
