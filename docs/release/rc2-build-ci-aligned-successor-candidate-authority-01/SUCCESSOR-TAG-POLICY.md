# Successor Tag Policy

Nom normatif : `appart-sn-release-candidate-rc2-r2`.

Justification : la famille publique RC reste `appart-sn-release-candidate-rc2`, tandis que le suffixe historique démontré `-r2` exprime une seconde matérialisation sans prétendre ouvrir RC3. Les formes `.1`, `-aligned` et `phase-5.9-rc2-r2` ne sont démontrées par aucune convention de tags existante.

Le tag doit être annoté, créé une seule fois après le commit successor, et résoudre exactement vers celui-ci. Le tag `appart-sn-release-candidate-rc2` reste intact.
