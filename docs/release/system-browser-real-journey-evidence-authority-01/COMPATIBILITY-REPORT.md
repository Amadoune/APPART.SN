# Rapport de compatibilité

Cette Authority ne modifie aucun fichier produit, contrat IAM, rôle, session policy, Authoring Runtime, Media Runtime, Listing Lifecycle, Publication Review, Projection ou Search.

Elle ne remplace aucune autorité applicative. Elle remplace uniquement le moyen de collecte navigateur indisponible par Chrome système qualifié, tout en exigeant les mêmes endpoints, décisions fermées, actors, ledgers, stores et replays.

Les règles fail-fast et de correction unique restent intégrales. F0–F7 restent fermées. Iteration 11 reste suspendue pendant cette décision. Iteration 12 et Search ne sont pas ouverts.
