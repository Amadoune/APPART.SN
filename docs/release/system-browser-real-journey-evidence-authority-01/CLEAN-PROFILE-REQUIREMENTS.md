# Exigences du profil propre

Le parcours futur commence dans un nouveau profil Chrome RC2 dédié et externe au workspace.

Avant navigation :

- absence de cookie pour `appart.test` ;
- absence de session antérieure ;
- absence de localStorage/sessionStorage injecté ;
- absence d'extension ;
- cache vide ou profil jamais utilisé ;
- aucune importation depuis un profil owner ou reviewer.

Le profil devient une pièce de campagne éphémère. Il n'est pas partagé entre owner et reviewer. Aucune valeur de cookie n'est exportée dans les preuves.
