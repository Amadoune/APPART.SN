# A-5.3-GLOBAL-PROOF-QUALIFICATION — Certification Plan

## Principe

La fondation Report reste inchangée et OUVERTE avec le statut :

**IMPLÉMENTATION CONFORME — GO NON PROPOSABLE**

## Preuve PostgreSQL

Étape obligatoire :

1. qualifier l'environnement et les processus de test sans modifier le code ;
2. lancer la campagne PostgreSQL complète avec une fenêtre suffisante ;
3. conserver uniquement un résultat terminal ;
4. enregistrer tests, assertions, durée et verdict.

Un nouveau timeout reste NON CONCLUSIF. Le ciblé 2/2 ne peut pas se substituer
à la campagne complète.

## Preuve Pint

Deux voies seulement sont conformes :

1. ouvrir un amendement versionné 5.3G autorisant la correction de formatage,
   puis exécuter Pint complet ;
2. ouvrir une décision de gouvernance versionnée autorisant explicitement une
   dérogation à la gate globale, avec analyse d'impact.

La voie 1 est recommandée si l'autorité souhaite restaurer la baseline. Aucune
des deux voies n'est ouverte par cet audit.

## Représentation future

Le GO Report pourra être représenté uniquement lorsque :

- PostgreSQL complet produit un PASS terminal ;
- Pint complet produit PASS, ou une dérogation versionnée préalable est
  certifiée ;
- Architecture, Unit, PHPStan et `git diff --check` restent verts.

## Interdictions

- aucune correction Report ;
- aucune correction 5.3G sans amendement ;
- aucun arrêt forcé ou manipulation d'environnement revendiqué comme preuve ;
- aucun timeout converti en PASS ;
- aucune ouverture Queue ou HTTP.
