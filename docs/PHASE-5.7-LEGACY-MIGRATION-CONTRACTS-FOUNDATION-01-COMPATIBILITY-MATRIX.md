# Legacy Migration & Reconciliation Contracts V1 — Compatibility Matrix

| Baseline | Compatibilité |
|---|---|
| Discovery / Blueprint 5.7 | Owner `LegacyMigration`, rôle de coordination et surfaces qualifiées conservés |
| Owners cibles | Aucune autorité transférée ; aucune dépendance vers leurs composants |
| Capacités 5.1 à 5.6 | GO FINALES CERTIFIÉES — FERMÉES — GELÉES, inchangées |
| Migrations antérieures | Inchangées et gelées |
| Persistence 5.7 | Non créée et non ouverte |
| Runtime/HTTP/Event/Delivery/Outbox | Non créés et non ouverts |

La Foundation ajoute uniquement des types Application read-only dans `LegacyMigration`. Aucun document Discovery 5.7 n'est modifié.
