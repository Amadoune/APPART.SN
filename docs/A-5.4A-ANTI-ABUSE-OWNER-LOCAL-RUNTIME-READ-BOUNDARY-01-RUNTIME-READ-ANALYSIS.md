# Runtime Read Analysis

## Point de lecture

`LeadIngressIntentId + LeadIngressAntiAbuseObservedAt → décision Runtime fermée`.

La future façade spécialisée sera seule autorisée à composer le port owner-local. Elle ne transmettra ni `AntiAbuseRevisionState`, ni révision, checksum, historique ou diagnostic Infrastructure.

## Responsabilités

- Persistence : journal et sélection temporelle ;
- Runtime existant : disponibilité technique ;
- future Runtime Read : lecture owner-locale et réduction interne ;
- futur Owner Reader : adaptation mécanique vers le catalogue public.

Le catalogue Runtime candidat est limité à `Allowed`, `Blocked`, `Missing`, `Corrupted` et `DependencyUnavailable`.
