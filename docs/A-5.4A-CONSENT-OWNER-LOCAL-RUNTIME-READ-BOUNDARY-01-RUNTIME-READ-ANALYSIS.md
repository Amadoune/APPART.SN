# Runtime Read Analysis

## Point exact de lecture

La lecture autorisée est :

`LeadIngressIntentId + LeadConsentObservedAt → décision Runtime fermée`.

La future implémentation Runtime spécialisée pourra seule composer le port
owner-local certifié. Le Reader public ne verra ni révision, ni checksum, ni
State, ni diagnostic Infrastructure.

## Responsabilités

- Runtime Health existant : disponibilité technique uniquement ;
- façade Runtime Read spécialisée : lecture temporelle et réduction interne ;
- Reader public : adaptation vers le catalogue public certifié ;
- Persistence : autorité append-only et sélection historique.

Le catalogue Runtime candidat devra rester fermé à `Granted`, `Denied`,
`Missing`, `Corrupted` et `DependencyUnavailable`. Il ne constitue pas un
nouveau catalogue métier mais une barrière anti-fuite entre Persistence et
Reader.
