# Certification

La frontière est Application-only, owner-scoped et déterministe. Elle consomme
la requête et l'instant d'observation réels, conserve la distinction `Found` /
`Empty`, masque `Missing` par une réduction fail-closed et ne divulgue aucune
identité interne. Aucun Provider, Runtime, SQL ou changement de contrat n'est créé.
