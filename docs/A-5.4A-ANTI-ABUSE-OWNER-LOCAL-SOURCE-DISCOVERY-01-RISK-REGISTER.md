# Anti-abuse Owner-local Source — Risk Register

| Risque | Niveau | Mitigation documentaire |
|---|---|---|
| confusion avec déduplication/rate limiting | élevé | source et finalité autonomes |
| motif ou données techniques excessifs | élevé | schéma minimal fermé |
| chronologie incohérente | élevé | versions et instants monotones |
| double append concurrent | élevé | PK, checksum et transaction locale |
| état courant promu autorité | élevé | journal seul autoritatif |
| reconstruction dérivée | élevé | aucun backfill Event/projection |
| cycle avec orchestration | élevé | source indépendante avant orchestration |
| rétention indéfinie | élevé | décision Privacy obligatoire avant purge |
| expiration implicite | élevé | aucun état `Expired` sans amendement |
| transaction distribuée | élevé | owner-local exclusivement |
