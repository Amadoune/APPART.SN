# Anti-abuse Owner-local Source — Temporal Read Matrix

| Situation à `observedAt` | Résultat conceptuel |
|---|---|
| aucune révision applicable | `Missing` |
| dernière décision applicable `Allowed` | `Allowed` |
| dernière décision applicable `Blocked` | `Blocked` |
| trou, ordre temporel ou checksum incohérent | `Corrupted` |
| source indisponible | `DependencyUnavailable` |

`effectiveAt` porte l'effet métier. `recordedAt` porte l'écriture owner-locale.
Une révision enregistrée plus tard ne réécrit jamais une observation historique.
Les instants sont UTC et canoniques à la microseconde.
