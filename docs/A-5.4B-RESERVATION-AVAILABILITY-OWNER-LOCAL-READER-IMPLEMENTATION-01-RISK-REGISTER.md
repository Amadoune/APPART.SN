# Risk Register

| Risque | Niveau | Garantie |
|---|---|---|
| logique métier dans le Reader | élevé | match bijectif exhaustif uniquement |
| accès direct Persistence | élevé | dépendance unique à Runtime Read V1 |
| fuite de State ou diagnostics | élevé | contrat public fermé sans payload interne |
| fallback implicite | élevé | match exhaustif sans branche par défaut |
| binding multiple | moyen | singleton et alias unique |
| ouverture HTTP/Event anticipée | élevé | absence contrôlée par Architecture |
