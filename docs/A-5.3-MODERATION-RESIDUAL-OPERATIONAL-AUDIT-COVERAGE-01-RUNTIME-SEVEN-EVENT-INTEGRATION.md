# Residual Runtime Audit Seven-Event Integration Foundation

## Catalogue fermé

Le Runtime Audit réel accepte exactement :

1. `moderation.report.submitted.v1`
2. `moderation.report.validated.v1`
3. `moderation.finding.recorded.v1`
4. `moderation.queue-item.claimed.v1`
5. `moderation.decision.issued.v1`
6. `moderation.case.closed.v1`
7. `moderation.target-action.completed.v1`

Le catalogue `ResidualOperationalAuditRuntimeCatalogV1` est injecté dans le
reader PostgreSQL réel. Tout huitième type est refusé avant toute conversion et
la Delivery est mise en quarantaine.

## Validation

Le reader restaure le transport canonique, reconstruit l'Event V1 avec les
classes historiques puis recalcule :

- eventId ;
- checksum ;
- messageId.

Il compare ces identités au transport persisté avec `hash_equals`. La
destination est fixée à `moderation.delivery-observation`; le claim owner et
l'état de Delivery sont validés par les updates conditionnels. Un payload
incomplet, un type inconnu ou une identité divergente est quarantiné
fail-closed avant l'append Audit.

## Conversion mécanique

`ModerationOperationalAuditRecordFactory` utilise exclusivement la matrice
fermée Event → opération Audit → clé opaque. Il n'injecte plus et ne consulte
plus `ModerationDecisionStore`.

La conversion n'accède à aucun Aggregate, Repository, Snapshot, SQL ou
historique propriétaire. Elle transmet uniquement les identifiants et
métadonnées déjà présents dans l'Event.

## Idempotence et exploitation

- premier traitement : `Applied` puis Delivery livrée ;
- replay identique : `AlreadyApplied`, aucun second record ;
- divergence : quarantaine sans écrasement ;
- indisponibilité : retry borné à trois tentatives ;
- payload ou transport corrompu : quarantaine immédiate ;
- Event inconnu : refus fail-closed.

`AdministrationAuditAppendV1`, sa persistence et son modèle transactionnel
owner-local restent inchangés.

## Bindings

Le container résout en singleton lazy :

- `PostgreSqlModerationOperationalAuditDeliveryReader` comme
  `ModerationOperationalAuditDeliveryReaderV1` ;
- `ModerationOperationalAuditRecordFactory` ;
- `ModerationOperationalAuditConsumer`.

Aucun mapper auxiliaire historique ni Decision Store ne participe au chemin
Runtime.

## Exclusions

Routing, Delivery, Outbox, Events V1, Runtime Health, HTTP, migrations,
AdministrationAudit et ses Providers restent inchangés. 5.3K et 5.3L restent
fermés.
