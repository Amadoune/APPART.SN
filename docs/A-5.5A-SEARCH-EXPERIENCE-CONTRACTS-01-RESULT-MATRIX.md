# A-5.5A Search Experience — Result Matrix

| Statut | Sens public | Payload |
|---|---|---|
| `Found` | la recherche possède au moins un résultat | aucun |
| `Empty` | la recherche ne possède aucun résultat | aucun |
| `Corrupted` | le résultat ne peut être considéré fiable | aucun |
| `DependencyUnavailable` | la décision est indisponible | aucun |

Le catalogue est fermé. Le résultat contient exclusivement le statut. Listing,
snippet, score, ranking, facette, pagination, diagnostic, index, checksum,
version, projection et cache sont interdits.
