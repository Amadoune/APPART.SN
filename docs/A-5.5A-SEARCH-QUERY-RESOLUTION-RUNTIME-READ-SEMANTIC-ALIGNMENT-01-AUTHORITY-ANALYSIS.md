# Authority Analysis

| Décision | Autorité légitime |
|---|---|
| disponibilité technique | Runtime Foundation |
| lecture temporelle d'une requête | source owner-locale SearchDiscovery |
| distinction Found / Empty | future frontière Query Resolution owner-scoped |
| adaptation vers le contrat public | futur Owner Reader |
| identité des documents et index | interne SearchDiscovery, jamais exposée |

`Found` et `Empty` ne peuvent naître qu'après réception de `SearchQuery`, prise
en compte de l'instant explicite et lecture de la source owner-locale.
