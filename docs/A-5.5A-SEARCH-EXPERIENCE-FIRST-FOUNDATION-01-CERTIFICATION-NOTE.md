# A-5.5A Search Experience First Foundation — Certification Note

La première Foundation exécutable recommandée est une Persistence Foundation
hybride owner `SearchDiscovery` : journal append-only autoritatif et index
courant dérivé/reconstruisible.

Identités existantes conservées : `SearchDocumentId`, `SearchIndexId`, référence
Listing opaque, version positive de `SearchDecision` et `SourceRevisionSet`.
`SearchDocumentIntent` n'est pas nécessaire. `SearchObservedAt` reste un instant
de lecture publique.

Les états `Visible`, `Hidden`, `Removed` restent internes. Les futures garanties
porteront sur atomicité owner-locale, idempotence, divergence fail-closed,
concurrence, savepoints, reconstruction, minimisation et rétention.

Aucun contrat, Runtime, Reader, Provider, Persistence, migration, SQL, HTTP,
Event, Delivery, Outbox, test ou composant exécutable n'est créé.
