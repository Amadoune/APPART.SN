# A-5.3 — Operational Audit Event & Routing Coverage — Discovery

## Statut

Boundary Audit documentaire. Aucun jalon, amendement ou travail technique n'est
ouvert par ce document.

## Objet

Qualifier la capacité réelle du catalogue Event V1 et du routing
ModerationReports à alimenter durablement l'audit opérationnel de la Phase
5.3K.

Une couverture est considérée comme durable uniquement si les quatre
conditions suivantes sont réunies :

1. un Event V1 certifié existe ;
2. le parcours métier produit cet Event après une mutation réussie ;
3. l'Event est persisté dans l'Outbox au sein de la transaction owner-local
   prévue par les fondations certifiées ;
4. une destination dédiée peut être réclamée par le consumer Audit sans
   détourner un consumer propriétaire existant.

L'existence d'un type dans un enum ne constitue donc pas, à elle seule, une
preuve de couverture.

## État réel du catalogue

| Parcours | Event V1 | État |
|---|---|---|
| ReportSubmitted | `moderation.report.submitted.v1` | existe |
| ReportValidated | `moderation.report.validated.v1` | existe |
| FindingRecorded | aucun Event V1 | absent |
| QueueItemClaimed | aucun Event V1 | absent |

Les événements historiques Domain `FindingRecorded` ne sont pas des contrats
Event V1 et ne peuvent pas être utilisés comme substituts.

## État réel du routing

| Event | Destinations certifiées | Couverture Audit |
|---|---|---|
| ReportSubmitted | `moderation.queue`, `moderation.timeline` | absente |
| ReportValidated | `moderation.queue`, `moderation.timeline` | absente |
| FindingRecorded | aucune | absente |
| QueueItemClaimed | aucune | absente |

La destination actuellement consommable par l'intégration 5.3K est
`moderation.delivery-observation`. Aucun des quatre parcours audités n'y est
routé.

## Émission durable

L'orchestrateur propriétaire exécute les six Commands V1, tandis que les
composants d'atomicité et d'Outbox existent séparément. Aucun point de
composition certifié ne démontre actuellement, pour les quatre parcours
audités, la chaîne complète :

```text
Command Applied
  -> Event V1
  -> append Outbox atomique
  -> destination Audit
```

La couverture ne peut donc pas être obtenue par une simple réutilisation du
consumer 5.3K.

## Conclusion du Discovery

La couverture Event V1 et Routing actuelle est insuffisante. Une extension
versionnée owner ModerationReports est indispensable avant toute reprise de
5.3K.
