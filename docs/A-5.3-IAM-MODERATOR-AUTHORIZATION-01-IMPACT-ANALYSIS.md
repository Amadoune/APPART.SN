# A-5.3-IAM-MODERATOR-AUTHORIZATION-01 — Impact Analysis

## Impact fonctionnel

L'amendement crée seulement une capacité contractuelle de lecture. Il ne change
aucune décision IAM existante et n'attribue aucune capacité de modération.

## Impact technique

| Élément | Impact |
|---|---|
| Aggregate Account | aucun |
| Roles et assignments | aucun |
| Account Availability | aucun |
| Persistence IAM | aucun |
| Migrations | aucune |
| Runtime et Runtime Health | aucun |
| Provider / binding | aucun |
| HTTP | aucun |
| Event / Delivery / Outbox | aucun |
| ModerationReports | aucun |

## Risque et confinement

Le risque principal serait qu'un consommateur traite un défaut comme une
autorisation. Le catalogue ferme ce risque : seul `Allowed` autorise l'action ;
`Denied`, `Corrupted` et `DependencyUnavailable` sont obligatoirement
fail-closed.

L'implémentation et le binding de cette frontière ne sont pas autorisés par le
présent amendement et nécessiteront un jalon explicite.
