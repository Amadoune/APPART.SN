# Phase 5.8B — Reliability & Operations — Runtime Foundation

Le Runtime expose exclusivement la disponibilité technique de `ReliabilityOperationsOwnerSource`.

Composants : `ReliabilityOperationsRuntimeV1`, Availability, AvailabilityPolicy, Diagnostics et leurs deux implémentations déterministes. Le Runtime ne dépend d'aucune autre source.

Il ne constitue ni un Runtime Read, ni un Reader public, ni une preuve d'état métier ou opérationnel détaillé.
