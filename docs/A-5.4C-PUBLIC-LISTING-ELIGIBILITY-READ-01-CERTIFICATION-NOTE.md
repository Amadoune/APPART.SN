# A-5.4C Public Listing Eligibility Read — Certification Note

## Recommandation

Retenir une future frontière publique V1, read-only et owner-scoped appartenant
à `ListingLifecycle`, interrogée par `ListingId` et par un instant UTC explicite.

Le catalogue candidat est fermé : `Eligible`, `NotEligible`, `Missing`,
`Corrupted`, `DependencyUnavailable`. Seul `Eligible` autorise Favorites à
poursuivre.

## Garanties

- aucune décision composite ;
- aucune exposition du lifecycle ou de données Listing ;
- aucune lecture Aggregate, Repository, Store, SQL, projection, cache ou Event ;
- aucune dépendance Runtime Health ;
- aucune modification de `ListingLifecycle`, Favorites ou d'une baseline gelée ;
- aucun code, contrat PHP, test, migration, Provider ou binding créé.

Le futur Contracts Amendment reste non ouvert par cet audit.
