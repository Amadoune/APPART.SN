# Editorial Content & Operational SEO — Contracts Risk Register

| Risque | Niveau | Maîtrise |
|---|---|---|
| Duplication d'une décision Listing | Élevé | Catalogues limités aux décisions `ContentSeo` |
| Fuite d'identité interne | Élevé | Clé publique opaque dédiée |
| Confusion Editorial/SEO | Élevé | Deux interfaces et deux catalogues distincts |
| Rendering devenu autorité | Élevé | Aucun contrat Rendering dans la Foundation |
| Horloge implicite | Moyen | `ContentSeoObservedAt` obligatoire, aucune méthode `now()` |
| Extension silencieuse du catalogue | Moyen | Enums V1 fermées et tests exhaustifs |
| Couplage backend | Élevé | Architecture sans Persistence, SQL ni Runtime |

Le risque résiduel d'interprétation du contenu sera traité par une future
Foundation explicitement ouverte ; il n'est pas résolu dans les contrats.
