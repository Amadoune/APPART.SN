# A-5.4B Reservation Availability Source — Temporal Read Matrix

| Dimension | Règle candidate |
|---|---|
| fenêtre | intervalle UTC semi-ouvert `[startsAt, endsAt)` |
| validité | `startsAt < endsAt` |
| instant d'effet | instant métier à partir duquel la révision s'applique |
| instant d'enregistrement | instant owner-local immuable de l'append |
| révision | entier strictement positif, monotone par intent |
| lecture historique | dernière révision effective et enregistrée au plus tard à `observedAt` |
| ordre | effectAt, puis revision ; recordedAt conserve la preuve d'arrivée |
| conflit | même sujet et intersection non vide avec un état bloquant |

Les intervalles adjacents `[a,b)` et `[b,c)` ne se chevauchent pas. Une
révision enregistrée après l'instant observé ne peut modifier rétroactivement
le résultat d'un replay historique.
