# A-5.3-MODERATION-REPORT-OWNER-READ-SOURCE-01 — Source Specification

## Séquence

```text
reportId
  → validation UUID
  → ModerationReportCaseIdentityV1
  → CanonicalModerationCommand
  → caseId canonique
  → PK lookup cases(case_id)
  → index lookup report_revisions(case_id, report_id, version desc)
  → mapper minimal
  → Found | Missing | Corrupted | DependencyUnavailable
```

## Sémantique

- dossier canonique absent : `Missing` ;
- dossier canonique présent sans report exact : `Corrupted` ;
- payload sans reporter valide : `Corrupted` ;
- erreur PostgreSQL : `DependencyUnavailable` ;
- ligne cohérente : `Found`.

## Non-responsabilités

La source ne décide pas si le compte appelant possède le rapport. Cette
comparaison appartiendra à la future Query `ReadOwnModerationReportV1`.
Elle ne produit aucune vue HTTP et ne révèle jamais directement son état.
