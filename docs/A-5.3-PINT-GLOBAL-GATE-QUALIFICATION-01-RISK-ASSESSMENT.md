# A-5.3-PINT-GLOBAL-GATE-QUALIFICATION-01 — Risk Assessment

| Option | Risque | Compatibilité |
|---|---|---|
| ignorer l'écart | GO avec gate obligatoire rouge | interdite |
| simple réserve | attribue correctement l'écart mais ne le résout pas | insuffisante |
| dérogation ad hoc | affaiblit rétroactivement la baseline qualité | non recevable |
| correction dans Report | mutation hors périmètre d'un composant gelé | interdite |
| amendement 5.3G ciblé | changement versionné, auditable et limité | conforme |

## Impact réel

L'impact observé est uniquement stylistique ; aucun défaut fonctionnel n'est
démontré. L'impact de gouvernance est toutefois bloquant, car la commande
globale retourne un code non nul.

## Risque de l'amendement futur

Le risque technique est faible si le diff est strictement limité aux trois
fixers signalés. Le risque de périmètre devient élevé si l'amendement modifie
transport, checksum, payload, Event V1, routing ou Delivery.

## Contrôles nécessaires

- diff limité au serializer 5.3G ;
- absence de changement sémantique ;
- Pint global PASS ;
- tests ciblés 5.3G ;
- Architecture et Unit complètes selon décision d'ouverture ;
- `git diff --check` PASS.
