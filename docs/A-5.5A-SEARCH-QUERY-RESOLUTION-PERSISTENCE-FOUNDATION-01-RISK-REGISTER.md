# Risk Register

| Risque | Réduction |
|---|---|
| index pris pour autorité | journal déclaré unique vérité durable |
| fuite de requête ou PII | empreinte seule persistée |
| divergence concurrente | verrou owner-local et optimistic locking |
| corruption silencieuse | checksum SHA-256 et lecture fail-closed |
| couplage cross-domain | aucune FK, cascade ou dépendance externe |
