# Runtime Read Risk Register

| Risque | Niveau | Mitigation certifiée |
|---|---|---|
| fuite de l'état Persistence | élevé | résultat sans State ni métadonnée |
| confusion Runtime Health / Runtime Read | élevé | interfaces, implémentations et Providers distincts |
| décision ouverte sur `Undecided` ou `Withdrawn` | élevé | réduction obligatoire vers `Denied` |
| indisponibilité technique propagée | élevé | capture fail-closed vers `DependencyUnavailable` |
| binding anticipé du Reader public | moyen | test Architecture d'absence |
| couplage Infrastructure | élevé | dépendance exclusive au port Application |
