# Idempotence & Concurrency Matrix

| Cas | Résultat |
|---|---|
| même révision, même checksum | AlreadyApplied |
| même révision, contenu différent | DivergentRevision |
| saut ou révision obsolète | VersionConflict |
| concurrence sur une requête | verrou transactionnel, un seul gagnant |

Les révisions sont positives, monotones et sans trou. Les savepoints préservent
les transactions appelantes.
