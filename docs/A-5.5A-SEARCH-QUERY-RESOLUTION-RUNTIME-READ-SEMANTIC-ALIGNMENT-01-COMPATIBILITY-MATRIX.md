# Compatibility Matrix

| Option | Compatibilité | Verdict |
|---|---|---|
| 1. Runtime Read technique conservée | duplique la Runtime, aucun Found/Empty légitime | rejetée |
| 2. Nouvelle frontière owner-scoped de résolution | préserve contrats, Persistence, Runtime et identités internes | retenue |
| 3. Extension Runtime/Runtime Read | confond santé et métier, menace les baselines gelées | rejetée |
| 4. Suppression de la candidate sans remplacement | élimine le défaut mais laisse le Reader incomposable | rejetée seule |

Le sort recommandé combine l'option 2 avec la mise hors composition définitive
de la candidate NO GO. Un retrait technique ultérieur reste séparé.
