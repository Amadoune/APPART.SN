# Search Query Resolution Contracts Specification

Owner : `SearchDiscovery`.

```text
SearchQueryResolutionReaderV1::read(
    SearchQuery,
    SearchQueryResolutionObservedAt
): SearchQueryResolutionResultV1
```

Le contrat est V1, read-only, déterministe, fail-closed et indépendant de tout
framework, Runtime ou Persistence. `SearchQuery` reste opaque, déclarative et
non normalisée. Aucune résolution n'est implémentée.
