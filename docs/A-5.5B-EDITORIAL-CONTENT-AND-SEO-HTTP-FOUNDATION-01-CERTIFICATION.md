# ContentSeo HTTP Certification

Jalon : `A-5.5B-EDITORIAL-CONTENT-AND-SEO-HTTP-FOUNDATION-01`.

La certification couvre les deux Controllers, leurs Requests, la ResponseFactory,
le marqueur HTTP V1, le ServiceProvider et les routes publiques.

Les preuves attendues sont les tests Unit ciblés, Feature HTTP, Architecture,
PHPStan, Pint et `git diff --check`. Aucun PostgreSQL supplémentaire n'est requis.
