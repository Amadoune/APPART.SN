# A-5.2B-MEDIA-ATTACHMENT-BOUNDARY-01 — Decision

## Décision d’autorité

**GO CERTIFIÉ — FERMÉ.**

La frontière `AttachReadyMediaAssetV1` est une extension Application additive
compatible avec F-06.

Elle préserve :

- Aggregate et invariants Media ;
- lifecycle Active/Removed/Archived ;
- optimistic locking et réservation MediaId ;
- migrations existantes ;
- Event V1, Runtime, HTTP, Delivery et Outbox ;
- absence de FK et transaction cross-domain.

## Conditions avant implémentation

- contrat public V1 et résultats fermés conformes au présent audit ;
- journal d’intents owner-scoped via migration additive postérieure à 057 ;
- transaction locale Media avec savepoints ;
- tests contractuels, rollback et concurrence ;
- aucune modification d’un fichier gelé sans nouvelle décision d’autorité.

La réserve de frontière est levée. Toute évolution ultérieure exige un nouvel
amendement versionné.
