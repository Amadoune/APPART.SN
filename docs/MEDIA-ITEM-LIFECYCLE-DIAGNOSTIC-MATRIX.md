# Media Item Lifecycle Diagnostic Matrix

| Diagnostic | Condition | Priorité |
|---|---|---:|
| `UnknownAction` | action `Unknown`, quel que soit l'état | 1 |
| `TerminalState` | `Remove` ou `Archive` depuis `Removed` ou `Archived` | 2 |

Les diagnostics ne contiennent aucune donnée de collection ou information technique.
