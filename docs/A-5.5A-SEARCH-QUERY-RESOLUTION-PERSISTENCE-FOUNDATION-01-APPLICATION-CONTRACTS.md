# Application Persistence Contracts

`SearchQueryResolutionOwnerSource` expose uniquement `append`, `read` et
`history`. Les résultats de lecture sont `Found`, `Empty`, `Missing`,
`Corrupted`, `DependencyUnavailable`. Les écritures sont `Applied`,
`AlreadyApplied`, `DivergentRevision`, `VersionConflict`, `Corrupted` ou
`DependencyUnavailable`.
