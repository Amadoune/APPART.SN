# Anti-abuse Owner-local Source — State and Lifecycle Model

## États persistés minimaux

- `Allowed` ;
- `Blocked`.

`Undecided` est représenté par l'absence de révision (`Missing`). `Revoked`
n'est pas nécessaire : une nouvelle révision `Blocked` retire un `Allowed`, et
une nouvelle révision `Allowed` lève un blocage. `Expired` est exclu tant
qu'aucune politique d'expiration n'est certifiée.

## Invariants

- première révision égale à 1 ;
- révision suivante égale à `current + 1` ;
- `effectiveAt` strictement croissant ;
- `recordedAt >= effectiveAt` et non décroissant ;
- aucune mise à jour ni suppression d'une révision ;
- lecture à un instant = dernière révision dont `effectiveAt <= observedAt`.
