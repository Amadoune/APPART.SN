# Policy Versioning

La policy porte l'identité normative `public-search-ranking-policy-v1`.

Toute modification de sens, direction, baseline, formule, input ou catalogue de facettes crée une nouvelle version. Une v2 ne doit jamais réinterpréter silencieusement une sortie v1.

Le mode de transport/persistance de cette identité sera qualifié par la réouverture de l'autorité de matérialisation ; aucun mécanisme n'est créé ici.
