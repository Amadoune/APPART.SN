# Baseline Rank

Toute annonce Published éligible sans signal de priorité certifié reçoit la baseline **0**.

Cette valeur est choisie normativement parce qu'elle est le minimum du domaine, représente l'absence de priorité additionnelle et permet une évolution additive future sans réinterpréter v1. Elle n'est reprise d'aucune fixture.

En v1, toutes les annonces éligibles reçoivent exactement cette baseline.
