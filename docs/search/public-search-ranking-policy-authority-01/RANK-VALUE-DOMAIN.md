# Rank Value Domain

| Élément | Décision |
|---|---|
| type | entier |
| minimum | 0 inclus |
| maximum | 10000 inclus |
| valeur neutre | 0 |
| valeurs invalides | tout entier inférieur à 0 ou supérieur à 10000 |

La plage technique du Value Object devient la plage normative. Cela n'autorise pas chaque valeur : seule une policy versionnée peut en choisir une.
