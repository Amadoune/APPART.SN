# Rank Evolution

La seule garantie admissible est abstraite : mêmes faits versionnés et même policy doivent produire le même rang.

Aucun changement source n'est actuellement autorisé à modifier le rang, car aucun lien normatif n'existe entre rank et :

- nouvelle révision Listing ;
- changement Property ;
- changement Media ;
- fraîcheur ;
- promotion commerciale.

Une future policy devra lister les signaux autorisés, leur version et leur effet. Clock courante, random, ordre d'arrivée, état Projection et input UI sont interdits.
