# Failure Modes

| Situation | Réduction attendue |
|---|---|
| source propriétaire absente | fail-closed, aucune décision |
| source corrompue | fail-closed, aucune décision |
| dépendance indisponible | fail-closed, rejeu possible |
| rang non résolu | blocage de matérialisation |
| facettes non résolues | blocage de matérialisation |
| révision incohérente | conflit, aucune écriture |

Les statuts applicatifs précis restent à contractualiser après la décision produit manquante.
