# Facet Ownership Matrix

| Responsabilité | Owner constaté |
|---|---|
| faits Property | Property |
| état et publication Listing | Listing Lifecycle |
| disponibilité Media | Media |
| hiérarchie géographique | Geography |
| validation/canonicalisation des facettes | SearchDiscovery |
| choix productif des facettes exposées | absent |

SearchDiscovery doit rester propriétaire de la projection Search. Il ne peut toutefois inventer la politique produit manquante.
