# Implementation Handoff

L'implémentation reste fermée.

Prérequis unique : une décision produit normative doit définir l'objectif du rang, son sens d'ordre, sa baseline, ses signaux autorisés et la matérialisation exacte des facettes depuis les owners. Elle devra aussi fermer les règles d'absence, d'évolution et de replay.

Après cette décision seulement, SearchDiscovery pourra composer les faits sans déplacer leur ownership.
