# Baseline Rank Decision

Question : existe-t-il un rang neutre pour toute annonce Published ?

Réponse : **non démontré**.

- `0` est seulement la borne minimale valide ;
- `100` est une fixture ;
- `500` et `600` sont des valeurs locales ;
- aucun document ne définit une neutralité ;
- aucun consumer ne révèle un sens d'ordre permettant d'inférer une neutralité.

Décision : aucune baseline n'est retenue. Ce point impose le NO GO.
