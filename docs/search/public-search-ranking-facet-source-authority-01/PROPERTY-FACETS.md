# Property Facets

Les faits Property peuvent fournir des candidats tels que le type ou des caractéristiques. Aucun contrat certifié ne décide actuellement leur correspondance avec `property_type`, `category`, `amenity` ou `feature`.

Les faits restent propriétaires de Property ; aucune copie dans Search n'est autorisée sans règle de matérialisation explicite.
