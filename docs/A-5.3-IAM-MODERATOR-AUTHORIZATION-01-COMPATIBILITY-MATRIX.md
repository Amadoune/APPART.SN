# A-5.3-IAM-MODERATOR-AUTHORIZATION-01 — Compatibility Matrix

| Frontière certifiée | Interaction | Compatibilité |
|---|---|---|
| F-17 Identity & Access | nouvelle lecture publique additive | compatible |
| Account | identifiant opaque uniquement | compatible |
| AccountAvailabilityInspector | aucune consommation ou modification | préservé |
| Roles IAM | aucune exposition ou mutation | préservés |
| ModerationReports 5.3A–5.3H | futur consommateur contractuel uniquement | non modifié |
| Runtime Health | aucune capacité ou binding ajouté | préservé |
| HTTP IAM | aucune route ni adaptation | préservé |
| Event / Delivery / Outbox | aucune interaction | préservés |

## Dépendances autorisées

- le contrat dépend du Value Object public `AccountId` appartenant à IAM ;
- il dépend de `DateTimeImmutable` pour rendre l'observation explicite ;
- il expose uniquement ses deux enums V1 propriétaires.

## Dépendances interdites

- Domain Aggregate `Account` ;
- `RoleAssignment` ou `RoleId` ;
- Repository, Snapshot ou SQL ;
- Laravel, PDO ou PostgreSQL ;
- Runtime interne et Provider ;
- composant ModerationReports.
