# A-5.3-MODERATION-REPORT-OWNER-READ-SOURCE-01 — Implementation Foundation

## Implémentation

`PostgreSqlModerationReportOwnerReadSourceV1` réside dans l'enclave :

`ModerationReports/Infrastructure/Persistence/PostgreSql`

Elle :

1. refuse un reportId invalide avec `Corrupted` ;
2. obtient le caseId via `ModerationReportCaseIdentityV1` ;
3. lit `cases` par clé primaire ;
4. sélectionne la révision exacte `(case_id, report_id)` par version
   décroissante ;
5. ne sélectionne que `case_id`, `report_id` et `actorAccountId` ;
6. retourne un résultat fermé.

## Absence de scan

La requête utilise :

- la PK `cases(case_id)` ;
- l'index existant
  `report_revisions(case_id, report_id, case_version DESC)`.

Elle ne contient aucune recherche globale par reportId.

## Mapper

`ModerationReportOwnerReadMapper` valide les trois UUID et l'égalité exacte du
reportId attendu. Toute divergence produit `Corrupted`.
