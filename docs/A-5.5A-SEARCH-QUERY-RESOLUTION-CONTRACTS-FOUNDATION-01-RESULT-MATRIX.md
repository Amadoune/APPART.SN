# Result Matrix

| Statut | Signification publique |
|---|---|
| `Found` | la résolution owner-scoped a trouvé un résultat |
| `Empty` | aucun résultat public |
| `Corrupted` | état non fiable, fail-closed |
| `DependencyUnavailable` | dépendance indisponible, fail-closed |

Le résultat ne porte que le statut. Aucun document, index, Listing, score,
ranking, pagination, facette, snippet, diagnostic, checksum ou version.
