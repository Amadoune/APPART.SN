# ContentSeo Event Certification

Jalon : `A-5.5B-EDITORIAL-CONTENT-AND-SEO-EVENT-FOUNDATION-01`.

La certification couvre les deux Events V1, leurs factories, payloads, types et
catalogues de statuts fermés.

Les preuves attendues sont Unit ciblés, Architecture, PHPStan, Pint et
`git diff --check`. Aucun PostgreSQL ni Feature HTTP n'est requis.
