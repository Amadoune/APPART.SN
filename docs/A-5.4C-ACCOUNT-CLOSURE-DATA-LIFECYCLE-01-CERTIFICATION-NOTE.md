# A-5.4C Account Closure Data Lifecycle — Certification Note

La recommandation proposée est la rétention owner-locale avec accès bloqué.

- fermeture et réouverture : autorité `IdentityAccess / Account Closure` ;
- collection, blocage, rétention et future purge : autorité `Favorites` ;
- aucune implication Listing ;
- aucune suppression cross-domain ni transaction distribuée ;
- aucune purge avant une décision Privacy/Erasure distincte ;
- restauration d'accès possible uniquement après `Reopened` et avant erasure.

Aucun contrat PHP, Runtime, Reader, Provider, Persistence, migration, SQL, HTTP,
Event, Delivery, Outbox, test ou composant exécutable n'est créé.
