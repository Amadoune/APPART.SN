# A-5.5A Search Experience Boundary — Dependency Matrix

| Producteur | Consommateur | Flux | Qualification |
|---|---|---|---|
| ListingLifecycle | SearchDiscovery | décision publique minimale d'indexabilité | obligatoire |
| RealEstateCatalog | SearchDiscovery | décision Property minimale | obligatoire selon composition |
| Media owner | SearchDiscovery | readiness minimale | obligatoire selon composition |
| SearchDiscovery | API Search | résultats, facettes, ranking et pagination | future frontière publique |
| SearchDiscovery | ContentSeo | état Search public minimal | autorisé, unidirectionnel |
| Public Projection | consumer public | rendu d'un résultat sélectionné | complémentaire |
| Search | Aggregate/Repository Listing | lecture directe | interdite |
| Search | projection interne/SQL étranger | lecture directe | interdite |
| Runtime Health | Search | décision d'indexabilité | interdite |
| ContentSeo | Search | mutation de ranking/index | interdite |

Aucun cycle Search ↔ Listing ou Search ↔ SEO n'est admis. Les écritures restent
strictement owner-locales.
