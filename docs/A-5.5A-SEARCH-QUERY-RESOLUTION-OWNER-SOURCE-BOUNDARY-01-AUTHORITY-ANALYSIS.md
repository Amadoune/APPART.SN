# Authority Analysis — Query Resolution Owner Source

`SearchDiscovery` possède seul la résolution d'une `SearchQuery` observée à un
instant explicite. `SearchQueryResolutionOwnerSource` possède la vérité durable
owner-locale ; la nouvelle frontière possède l'adaptation publique de cette vérité.

Persistence conserve journal, index dérivé et identités internes. Runtime conserve
la disponibilité technique. La frontière owner-scoped produit seule le catalogue
public. L'Owner Reader futur ne pourra qu'adapter ce catalogue sans décider.

`SearchDocumentId`, `SearchIndexId`, `ListingId`, révision, checksum et diagnostics
restent internes. ListingLifecycle, Projection publique et Runtime Health ne
participent pas à la décision.
