# A-5.1-IAM-OUTBOX-CONCURRENCY-01 — Amendment

## Statut

```text
A-5.1-IAM-OUTBOX-CONCURRENCY-01
→ GO CERTIFIÉ
→ FERMÉ
→ IMPLÉMENTÉ
```

## Périmètre

L'amendement corrige exclusivement la convergence concurrente de l'insert
`event_outbox_messages`. Aucun schéma, migration, contrat Event V1, résultat
Outbox, Runtime, HTTP, Runtime Health, Historical Account ou Account Status
n'est modifié.

La correction remplace :

```sql
ON CONFLICT (message_id) DO NOTHING
```

par :

```sql
ON CONFLICT DO NOTHING
```

La comparaison canonique existante reste ensuite l'unique autorité pour
distinguer `AlreadyApplied` de `DivergentMessage`.
