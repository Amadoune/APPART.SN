# Application Persistence Contracts

`SearchOwnerSource` expose seulement `append`, `read` temporel et `history`.
`SearchOwnerRevisionState` porte `SearchDocumentId`, révision, décision,
`SearchDecision`, `effectiveAt` et `recordedAt`. Les résultats fermés sont :

- lecture : `Found`, `Missing`, `Corrupted`, `DependencyUnavailable` ;
- écriture : `Applied`, `AlreadyApplied`, `DivergentRevision`,
  `VersionConflict`, `Corrupted`, `DependencyUnavailable`.

Le port Application ne dépend ni de PDO, ni de PostgreSQL, ni d'un framework.
