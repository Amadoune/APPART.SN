# Editorial Content & Operational SEO — Source Inventory

## Sources owner-locales

- politiques canonical et historique de canonical ;
- directives robots et indexabilité SEO ;
- matériaux éditoriaux et structured data ;
- décisions sitemap ;
- snapshots de sources observées, sans autorité sur les domaines producteurs.

## Sources publiques candidates

- Listing : décision publique minimale de publication/indexabilité ;
- Media : média public qualifié et URL publique ;
- Geography : lieu public qualifié ;
- Search : résultat public certifié, seulement si un cas éditorial futur le requiert ;
- Identity : décision d'autorisation d'acteur, sans profil ni donnée privée.

Les contrats concrets restent à qualifier dans un jalon ultérieur. Aucun accès
direct aux Persistences, projections internes ou Runtimes sources n'est admis.
