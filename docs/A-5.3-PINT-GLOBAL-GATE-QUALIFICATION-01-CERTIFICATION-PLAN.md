# A-5.3-PINT-GLOBAL-GATE-QUALIFICATION-01 — Certification Plan

## Décision à solliciter

Ouverture explicite d'un amendement versionné 5.3G de restauration de la gate
Pint globale.

## Périmètre recommandé

Autoriser uniquement les transformations de formatage signalées par Pint dans :

```text
app/Application/ModerationEventTransport/ModerationEventTransportSerializer.php
```

Interdire toute modification de comportement, contrat, Event V1, checksum,
transport, routing, Delivery, Outbox, Runtime, migration ou Report.

## Preuves attendues

1. diff exact du fichier ;
2. Pint ciblé PASS ;
3. Pint global PASS avec exit code 0 ;
4. tests 5.3G ciblés PASS ;
5. campagnes de non-régression fixées par l'autorité ;
6. `git diff --check` PASS ;
7. confirmation d'absence de modification sémantique.

## Effet attendu

Après certification de l'amendement :

- gate Pint globale levée ;
- aucune réserve globale restante pour la fondation Report ;
- représentation de
  `A-5.3-MODERATION-REPORT-OWNER-READ-SOURCE-01` autorisable.

## Prochaine décision strictement autorisable

Ouverture de l'amendement 5.3G de formatage. Aucun Queue, HTTP, 5.3K ou 5.3L
n'est ouvert.
