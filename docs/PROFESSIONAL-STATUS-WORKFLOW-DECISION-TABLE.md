# Professional Status Workflow Decision Table

La table normative est la matrice exhaustive `2 états × 3 actions = 6 décisions`.

- transitions autorisées : 2 ;
- refus explicites : 4 ;
- états implicites : 0 ;
- dépendances externes : 0 ;
- sources temporelles : 0.

À entrée identique, l'objet décisionnel obtenu est structurellement identique.
