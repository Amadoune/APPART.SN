# ContentSeo HTTP Risk Register

| Risque | Maîtrise |
|---|---|
| Décision métier dans HTTP | Mapping fermé et mécanique |
| Accès direct Owner Source | Dépendances limitées aux Readers V1 |
| Fuite Infrastructure ou SQL | Contrôle Architecture ciblé |
| Paramètre métier supplémentaire | Requests à catalogue de champs fermé |
| Divulgation interne | Réponse limitée au statut public |
| Modification migration 078 | Empreintes SHA-256 contrôlées |
