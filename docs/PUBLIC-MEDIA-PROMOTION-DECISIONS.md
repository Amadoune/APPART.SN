# Décisions de promotion Public Media

| Décision | Condition | Promotable |
|---|---|---|
| Initial | aucune révision stable | oui |
| Advance | version Candidate strictement supérieure | oui |
| AlreadyStable | version, checksum et causalité identiques | non, aucun effet nécessaire |
| Obsolete | version Candidate inférieure | non |
| Divergent | même version, fait différent | non |

Les cinq décisions sont exhaustives. Aucune branche par défaut, réparation automatique ou promotion silencieuse n’est autorisée.
