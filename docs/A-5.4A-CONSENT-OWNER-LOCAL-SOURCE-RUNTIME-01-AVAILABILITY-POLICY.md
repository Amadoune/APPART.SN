# Runtime Availability Policy

La politique réalise une inspection déterministe du port certifié avec une
identité technique stable et un instant explicite. Un résultat `Found` ou
`Missing` prouve que la source répond correctement et produit `Available`.

| Résultat source | Diagnostic Runtime |
|---|---|
| `Found`, `Missing` | `Available` |
| `Corrupted` | `Corrupted` |
| `DependencyUnavailable` | `DependencyUnavailable` |

Le catalogue est fermé et fail-closed. Aucun SQL, PDO, message d'exception ou
détail PostgreSQL ne traverse la façade.
