# Risk Register

| Risque | Qualification / maîtrise |
|---|---|
| Query transformée en identifiant unique | interdit : cardinalité zéro-à-plusieurs |
| logique dans l'Owner Reader | interdite : Reader adaptateur seulement |
| modification Runtime Read gelée | éviter par frontière additive spécialisée |
| fuite index/Persistence | résultat owner-scoped minimal, aucun identifiant interne |
| projection ou cache autoritaire | explicitement exclus |
| duplication de logique Search | autorité unique `SearchDiscovery` |
| ranking anticipé | hors périmètre ; aucune sémantique définie par l'audit |
