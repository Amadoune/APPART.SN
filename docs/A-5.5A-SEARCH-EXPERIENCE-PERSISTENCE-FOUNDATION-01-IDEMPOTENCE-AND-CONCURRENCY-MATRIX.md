# Idempotence & Concurrency Matrix

| Situation | Résultat |
|---|---|
| nouvelle révision suivante | `Applied` |
| replay checksum identique | `AlreadyApplied` |
| même numéro, checksum distinct | `DivergentRevision` |
| trou, recul ou chronologie invalide | `VersionConflict` |
| deux append concurrents | verrou owner-local, un seul gagnant |

Le checksum de révision est un SHA-256 canonique. Les savepoints préservent la
transaction appelante et tout échec annule journal et index ensemble.
