# Lead Eligibility Negative Decision Persistence Matrix

| Décision Listing | Décision Advertiser | Stockage explicite |
|---|---|---|
| `Missing` | `Missing` | oui, avec révision complète |
| `NotPublished` | `Suspended` | oui, avec révision complète |
| `Closed` | `NotListingRecipient` | oui, avec révision complète |

Chaque décision négative peut être courante, remplacée par une version continue et reste accessible dans l'historique. Une absence physique retourne `SourceAbsent`, jamais une décision Domain.
