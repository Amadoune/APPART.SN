# A-5.5A Search Experience Boundary — Source Inventory

| Source | Owner / nature | Usage autorisé | Limite |
|---|---|---|---|
| Listing Aggregate/lifecycle | `ListingLifecycle`, autorité interne | aucune lecture directe | frontière publique requise |
| `SearchDiscovery` | owner Search existant | index, policy, ranking et décisions Search | ne possède pas les faits Listing |
| SearchDecision reader/store | Search, persistence owner-locale | future source des résultats | aucune exposition directe aux consumers |
| Public Listing Projection | projection de rendu | lien/rendu après résultat | jamais autorité d'indexabilité |
| Property source | `RealEstateCatalog` | fait public minimal | pas d'Aggregate direct |
| Media source | Media owner | readiness publique minimale | pas de Store direct |
| ContentSeo | owner SEO | consomme un état Search minimal | ne pilote pas Search |
| Events | transport/replay | alimentation future versionnée | jamais lecture ad hoc comme vérité |
| Runtime Health | diagnostic technique | disponibilité seulement | jamais décision métier |
| cache | optimisation Search | sous contrôle Search | jamais autorité source |

Le code historique `SearchDiscovery` confirme un owner et une projection
existants ; il ne vaut pas ouverture d'une Foundation 5.5A.
