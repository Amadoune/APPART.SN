# ContentSeo HTTP Foundation

La façade HTTP publique expose exclusivement les décisions des contrats V1
`EditorialContentReaderV1` et `OperationalSeoReaderV1`.

Les endpoints sont `GET /api/content-seo/editorial-content` et
`GET /api/content-seo/operational-seo`. Ils exigent `resourceKey` et un
`observedAt` explicite à la microseconde. Les réponses ne contiennent que le
statut public.

Aucune décision métier, Persistence, Runtime interne, Event, Delivery ou Outbox
n'est introduite.
