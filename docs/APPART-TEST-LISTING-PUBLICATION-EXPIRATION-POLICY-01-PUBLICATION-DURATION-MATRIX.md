# Publication Duration Matrix

| Dimension | Preuve disponible | Qualification |
|---|---|---|
| Durée par défaut | aucune valeur approuvée | MISSING |
| Type d'annonce | aucune règle observée | UNKNOWN |
| Plan/professionnel | le blueprint interdit une prolongation commerciale silencieuse ; aucune grille approuvée | UNKNOWN |
| Pays | aucune règle observée | UNKNOWN |
| Publication initiale | échéance exigée et connue dès publication, durée non définie | PARTIAL |
| Renouvellement simple | ouvre une nouvelle période, durée non définie | PARTIAL |
| Republication | aucune règle de nouvelle échéance | MISSING |
| Suspension/compensation | compensation seulement selon règle approuvée, règle absente | MISSING |
| Fixe ou configurable | non arbitré | UNKNOWN |
| Autorité finale | Listing Lifecycle candidat naturel, décision métier absente | BLOCKED |

Les durées utilisées dans les tests sont des données de scénario. Elles ne prouvent ni une durée standard, ni une équivalence métier entre publication initiale et renouvellement.
